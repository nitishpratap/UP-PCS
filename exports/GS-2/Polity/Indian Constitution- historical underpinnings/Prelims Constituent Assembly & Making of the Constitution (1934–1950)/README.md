# 1. DEMAND FOR CONSTITUENT ASSEMBLY


| Year     | Event                                                        |
| -------- | ------------------------------------------------------------ |
| **1934** | Idea proposed by **M. N. Roy**                               |
| **1935** | **INC officially demanded** CA                               |
| **1938** | **Nehru:** Constitution by **CA elected on adult franchise** |
| **1940** | **August Offer** accepted idea in principle                  |
| **1942** | **Cripps Mission** proposed constitution after WWII          |
| **1946** | **Cabinet Mission Plan created CA**                          |


### Key Fact


Muslim League rejected Cripps Plan because it demanded **two Constituent Assemblies (Pakistan demand)**.

# 5. METHOD OF ELECTION


| Feature                | Detail                             |
| ---------------------- | ---------------------------------- |
| Election type          | **Indirect**                       |
| Electors               | Provincial Legislative Assemblies  |
| Voting system          | **Proportional Representation**    |
| Method                 | **Single Transferable Vote (STV)** |
| Princely State members | **Nominated by rulers**            |


Important:


❗ **Constituent Assembly NOT elected by universal adult franchise**


Reason → Limited franchise under **Government of India Act 1935**.

# 9. OBJECTIVES RESOLUTION (Foundation of Preamble)


| Event      | Date            |
| ---------- | --------------- |
| Introduced | **13 Dec 1946** |
| Adopted    | **22 Jan 1947** |


Introduced by → **Jawaharlal Nehru**


### Key Principles

- India → **Independent Sovereign Republic**
- India → **Union of territories**
- Power derived from **People of India**
- **Justice, Equality, Liberty**
- Safeguards for **minorities & backward classes**
- **World peace commitment**

✔ **Modified Objectives Resolution → Preamble of Constitution**


---


# 10. CHANGES AFTER INDIAN INDEPENDENCE ACT 1947


### 1. Assembly Became Sovereign

- Could **make or repeal any law**

---


### 2. Dual Role


Assembly performed two roles:


| Function            | Presiding Officer       |
| ------------------- | ----------------------- |
| Constitution making | **Dr. Rajendra Prasad** |
| Legislative body    | **G. V. Mavlankar**     |


Thus it became **Dominion Legislature (First Parliament of Free India)**.


---


### 3. Membership Reduced


After partition → **389 → 299**
