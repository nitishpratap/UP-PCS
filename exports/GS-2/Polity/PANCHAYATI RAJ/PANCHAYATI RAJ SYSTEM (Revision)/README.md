# EVOLUTION OF PANCHAYATI RAJ


## BALWANT RAI MEHTA COMMITTEE (1957)


| Aspect           | Details                                 |
| ---------------- | --------------------------------------- |
| Appointed        | January 1957                            |
| Purpose          | Examine **CDP (1952)** & **NES (1953)** |
| Report Submitted | November 1957                           |
| Chairman         | **Balwant Rai G. Mehta**                |
| Key Idea         | **Democratic Decentralisation**         |


## Major Recommendations


### 3-Tier Structure


| Level    | Institution      |
| -------- | ---------------- |
| Village  | Gram Panchayat   |
| Block    | Panchayat Samiti |
| District | Zila Parishad    |


### Other Recommendations

- Gram Panchayat → **Direct election**
- Panchayat Samiti & Zila Parishad → **Indirect election**
- Panchayat Samiti → **Executive body**
- Zila Parishad → **Advisory + supervisory body**
- District Collector → Chairman of Zila Parishad
- Transfer planning & development functions
- Adequate financial resources
- Genuine devolution of powers

## Implementation


| Aspect         | Details                             |
| -------------- | ----------------------------------- |
| Accepted by    | National Development Council (1958) |
| First State    | Rajasthan                           |
| Launch Date    | 2 October 1959                      |
| Place          | Nagaur                              |
| Inaugurated by | Jawaharlal Nehru                    |
| Second State   | Andhra Pradesh                      |


## State Variations


| State       | Structure |
| ----------- | --------- |
| Rajasthan   | 3-tier    |
| Tamil Nadu  | 2-tier    |
| West Bengal | 4-tier    |


### Powerful Institution


| Model                      | Dominant Institution |
| -------------------------- | -------------------- |
| Rajasthan & Andhra Pradesh | Panchayat Samiti     |
| Maharashtra & Gujarat      | Zila Parishad        |


### Nyaya Panchayats

- Minor civil & criminal disputes settlement.

# ASHOK MEHTA COMMITTEE (1977)


| Aspect          | Details               |
| --------------- | --------------------- |
| Appointed       | December 1977         |
| Government      | Janata Government     |
| Report          | August 1978           |
| Recommendations | 132                   |
| Goal            | Revive Panchayati Raj |


## Major Recommendations


| Topic                 | Recommendation                               |
| --------------------- | -------------------------------------------- |
| Structure             | **2-tier system**                            |
| Levels                | Zila Parishad + Mandal Panchayat             |
| Mandal Panchayat      | Group of villages (15,000–20,000 population) |
| Main Unit             | District                                     |
| Zila Parishad         | Executive + district planning body           |
| Political Parties     | Participation in Panchayat elections         |
| Taxation              | Compulsory taxation powers                   |
| Social Audit          | By district agency/legislators committee     |
| Supersession          | Elections within 6 months                    |
| Nyaya Panchayat       | Separate body headed by judge                |
| Elections             | Conducted by Chief Electoral Officer         |
| Development Staff     | Under Zila Parishad                          |
| Reservation           | SC/ST proportional reservation               |
| Constitutional Status | Recommended                                  |


## Implementation

- Not implemented nationally due to collapse of Janata Government.
- Partially adopted in:
    - Karnataka
    - West Bengal
    - Andhra Pradesh

# G.V.K. RAO COMMITTEE (1985)


| Aspect       | Details                                        |
| ------------ | ---------------------------------------------- |
| Appointed by | Planning Commission                            |
| Purpose      | Rural development & poverty alleviation review |


## Key Observation

> “Grass without roots”

Meaning → Development without grassroots democracy.


## Recommendations

- Zila Parishad = Main development institution
- District = Main planning unit
- PRIs should handle planning, implementation & monitoring
- District Development Commissioner as CEO of Zila Parishad
- Regular Panchayat elections
- Reduced role of District Collector

# 73rd CONSTITUTIONAL AMENDMENT ACT, 1992


| Aspect              | Details           |
| ------------------- | ----------------- |
| Passed              | December 1992     |
| Presidential Assent | 20 April 1993     |
| Effective From      | 24 April 1993     |
| Added               | Part IX           |
| Articles            | 243–243O          |
| Schedule Added      | Eleventh Schedule |
| Subjects            | 29                |


## Significance

- Constitutional status to Panchayats
- Regular elections compulsory
- Strengthened grassroots democracy
- Implemented Article 40

---


# COMPULSORY VS VOLUNTARY PROVISIONS


## COMPULSORY PROVISIONS

- Gram Sabha
- 3-tier system
- Direct elections
- Indirect election of chairpersons at higher levels
- Minimum age = 21 years
- SC/ST reservation
- 1/3 reservation for women
- 5-year tenure
- State Election Commission
- State Finance Commission every 5 years

---


## VOLUNTARY PROVISIONS

- MPs/MLAs representation
- OBC reservation
- Self-government powers
- Development & social justice functions
- Taxation powers

| ------------ | ---------------- |

- Reservation proportional to population.

- Minimum 1/3 seats reserved.

- 1/3 chairperson posts reserved.

### OBC

- Optional for states.

---

| Aspect                        | Provision                      |
| ----------------------------- | ------------------------------ |
| Tenure                        | 5 years                        |
| Re-election after dissolution | Within 6 months                |

# PESA ACT, 1996


## Full Form


**Panchayats (Extension to Scheduled Areas) Act, 1996**


## Why Needed?

- 73rd Amendment not applicable to Fifth Schedule Areas.

---


## States Having Fifth Schedule Areas

1. Andhra Pradesh
2. Telangana
3. Chhattisgarh
4. Gujarat
5. Himachal Pradesh
6. Jharkhand
7. Madhya Pradesh
8. Maharashtra
9. Odisha
10. Rajasthan

---


# OBJECTIVES OF PESA

- Tribal self-governance
- Participatory democracy
- Protection of tribal customs
- Prevent domination by higher Panchayats
- Administrative system compatible with tribal traditions

---


# FEATURES OF PESA


| Topic              | Provision                                                     |
| ------------------ | ------------------------------------------------------------- |
| Customary laws     | Must be respected                                             |
| Village definition | Habitation/hamlet/group                                       |
| Gram Sabha         | All registered voters                                         |
| Gram Sabha powers  | Protect traditions & resources                                |
| Development role   | Approve plans & beneficiaries                                 |
| Fund utilisation   | Gram Sabha certification mandatory                            |
| ST Reservation     | Not less than 50%                                             |
| Chairperson posts  | Reserved for STs                                              |
| ST Nomination      | Max 10%                                                       |
| Land acquisition   | Gram Sabha consultation                                       |
| Mining leases      | Gram Sabha recommendation mandatory                           |
| Additional powers  | Liquor regulation, MFP ownership, markets, money lending etc. |
