# 1️⃣ Ultra-Short Revision (Prelims)


### Core Definition

- **Preamble** = _Introduction / Preface of the Constitution_.
- Contains **philosophy, ideals and objectives** of the Constitution.
- **N.A. Palkhivala** → _“Identity Card of the Constitution”_.

---


### Source of the Preamble


| Feature   | Fact                      |
| --------- | ------------------------- |
| Based on  | **Objectives Resolution** |
| Moved by  | **Jawaharlal Nehru**      |
| Presented | **13 Dec 1946**           |
| Adopted   | **22 Jan 1947**           |


---


### Adoption of Constitution


| Event                        | Date            |
| ---------------------------- | --------------- |
| Constitution adopted         | **26 Nov 1949** |
| Constitution came into force | **26 Jan 1950** |


---


### Amendment of Preamble


Only **one amendment**.


| Amendment                         | Year | Added Words                   |
| --------------------------------- | ---- | ----------------------------- |
| **42nd Constitutional Amendment** | 1976 | Socialist, Secular, Integrity |


---


### Nature of Indian State


India is a:


**Sovereign – Socialist – Secular – Democratic – Republic**


---


### Objectives of the Constitution

- **Justice** – Social, Economic, Political
- **Liberty** – Thought, Expression, Belief, Faith, Worship
- **Equality** – Status & Opportunity
- **Fraternity** – Dignity of Individual + Unity & Integrity

# Meaning and Nature of the Preamble


The **Preamble** acts as the **philosophical foundation of the Constitution**.


It explains:

- **Source of authority**
- **Nature of the Indian state**
- **Objectives of the Constitution**
- **Date of adoption**

---


## Components of the Preamble


| Component           | Explanation                                         |
| ------------------- | --------------------------------------------------- |
| Source of Authority | **People of India**                                 |
| Nature of State     | Sovereign, Socialist, Secular, Democratic, Republic |
| Objectives          | Justice, Liberty, Equality, Fraternity              |
| Adoption Date       | **26 November 1949**                                |


---


# Key Terms in the Preamble


## 1️⃣ Sovereign


Meaning:

- India is **independent internally and externally**.
- No external authority controls India.

Historical status:


| Period      | Status             |
| ----------- | ------------------ |
| Before 1947 | British Colony     |
| 1947–1950   | Dominion           |
| After 1950  | Sovereign Republic |


Membership of:

- **United Nations**
- **Commonwealth**

does **not affect sovereignty**.


---


## 2️⃣ Socialist


Added by **42nd Amendment (1976)**.


India follows **Democratic Socialism**.


| Democratic Socialism    | Communist Socialism |
| ----------------------- | ------------------- |
| Mixed economy           | State ownership     |
| Public + Private sector | Only state sector   |
| Democratic system       | Authoritarian       |


Objectives:

- Reduce inequality
- Remove poverty
- Promote welfare state

1991 reforms (**LPG**) reduced the intensity of socialism.


---


## 3️⃣ Secular


Added by **42nd Amendment (1976)**.


Indian secularism = **Equal respect for all religions**.


Key features:

- No official state religion
- State protects all religions equally

Relevant Articles:


| Article | Provision                   |
| ------- | --------------------------- |
| 25      | Freedom of religion         |
| 26      | Manage religious affairs    |
| 27      | No tax for religion         |
| 28      | Religious instruction rules |


Type: **Positive Secularism**


---


## 4️⃣ Democratic


Democracy means **power ultimately rests with the people**.


Origin:


Greek words


| Word   | Meaning |
| ------ | ------- |
| Demos  | People  |
| Kratia | Rule    |


India follows:


**Representative Parliamentary Democracy**


Features:

- Universal adult franchise
- Periodic elections
- Rule of law
- Independent judiciary

---


## 5️⃣ Republic


Republic means:

- Head of state **elected**, not hereditary.
- In India → **President**

| Feature  | Detail   |
| -------- | -------- |
| Election | Indirect |
| Tenure   | 5 years  |


Implications:

- Political sovereignty with people
- No privileged class

---


# Justice


The Constitution ensures **three forms of justice**.


| Type              | Meaning                     |
| ----------------- | --------------------------- |
| Social Justice    | No social discrimination    |
| Economic Justice  | Fair distribution of wealth |
| Political Justice | Equal political rights      |


Sources:

- **Fundamental Rights**
- **Directive Principles**

Inspired by **Russian Revolution (1917)**.


---


# Liberty


Liberty ensures **freedom of individual development**.


Protected liberties:

- Thought
- Expression
- Belief
- Faith
- Worship

However, liberty is **not absolute**.


Restrictions exist for:

- Security of state
- Public order
- Morality

Inspired by **French Revolution**.


---


# Equality


The Constitution guarantees:


**Equality of Status and Opportunity**


### Dimensions of Equality


| Dimension          | Meaning                        |
| ------------------ | ------------------------------ |
| Civic Equality     | Equality before law            |
| Political Equality | Equal voting rights            |
| Economic Equality  | Equal livelihood opportunities |


---


# Fraternity


Fraternity promotes **brotherhood among citizens**.


Objectives:


1️⃣ **Dignity of the Individual**


2️⃣ **Unity and Integrity of the Nation**


Mechanisms promoting fraternity:

- **Single citizenship**
- **Fundamental Duties (Art 51A)**

Threats to unity:

- Communalism
- Regionalism
- Casteism
- Linguism
- Secessionism
