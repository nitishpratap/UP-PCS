# 1. GLOBAL SCENARIO & NEED FOR OMBUDSMAN


## Welfare State → Expansion of Administration


Modern democratic states are **Welfare States**, therefore:

- Govt role in socio-economic development ↑
- Bureaucracy expanded
- Administrative discretion increased

### Consequences


Excessive administrative power leads to:

- Harassment
- Maladministration
- Corruption
- Abuse of authority
- Delay & arbitrariness

Hence, citizens need:


✔ Grievance redressal


✔ Administrative accountability


✔ Control over misuse of power

# 3. OMBUDSMAN SYSTEM


## Origin


| Feature | Detail                                           |
| ------- | ------------------------------------------------ |
| Country | Sweden                                           |
| Year    | 1809                                             |
| Nature  | First democratic grievance redressal institution |


### Meaning


“Ombud” = representative/spokesman.


### Donald C. Rowat

> Ombudsman is an officer appointed by legislature to handle complaints against administrative and judicial actions.

---


# 4. FUNCTIONS OF SWEDISH OMBUDSMAN


| Area                | Meaning                       |
| ------------------- | ----------------------------- |
| Abuse of discretion | Arbitrary/misuse of power     |
| Maladministration   | Delay, inefficiency           |
| Corruption          | Bribe-taking                  |
| Nepotism            | Favouritism in jobs/contracts |
| Discourtesy         | Misbehaviour, harassment      |


---


# 5. APPOINTMENT & STATUS


| Feature             | Detail                  |
| ------------------- | ----------------------- |
| Appointed by        | Parliament              |
| Tenure              | 4 years                 |
| Removal             | By Parliament           |
| Report submitted to | Parliament              |
| Hence called        | Parliamentary Ombudsman |


### Independent of:

- Legislature
- Executive
- Judiciary

---


# 6. POWERS OF OMBUDSMAN


Supervises legality & proper functioning of:

- Civil officials
- Judicial officials
- Military officials

Ensures:

- Impartiality
- Objectivity
- Rule of law

---


# 7. LIMITATIONS OF OMBUDSMAN


## Cannot:

- Reverse decisions
- Quash orders
- Directly punish officials
- Control administration directly

## Can:


✔ Prosecute erring officials


✔ Investigate judges also


Punishment imposed by competent authority.


---


# 8. INVESTIGATION INITIATION


| Type            | Meaning                 |
| --------------- | ----------------------- |
| Complaint-based | Citizen files complaint |
| Suo moto        | Ombudsman acts on own   |

# 9. FEATURES OF OMBUDSMAN SYSTEM

# 41. DRAWBACKS OF LOKPAL ACT


| Drawback                        | Explanation                |
| ------------------------------- | -------------------------- |
| No suo moto power               | Acts only on complaint     |
| Technical complaint format      | Form > substance           |
| Punishment for false complaints | Discourages whistleblowers |
| Anonymous complaints barred     | Identity compulsory        |
| Legal assistance to accused     | May delay inquiry          |
| Limitation period               | Only within 7 years        |
| PM inquiry opaque               | Non-transparent process    |
