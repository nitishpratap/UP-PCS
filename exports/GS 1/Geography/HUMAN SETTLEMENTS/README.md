
# 1. Human Settlement – Meaning


### Definition


**Human Settlement:**


A **cluster of dwellings** of any type or size where people live and organise their economic activities.


**Key Components**

1. **People** – population living together
2. **Dwelling houses** – physical structures
3. **Territory** – surrounding land used for livelihood
4. **Economic base** – agriculture, industry, services

➡ Settlement formation involves:


```plain text
Grouping of People
        ↓
Construction of Houses
        ↓
Control of Territory
        ↓
Use of Land Resources
```


---


# 2. Size and Types of Settlements


Settlements vary from **very small hamlets to large metropolitan cities**.


| Type              | Size             | Activities          |
| ----------------- | ---------------- | ------------------- |
| Hamlet            | Very small       | Primary activities  |
| Village           | Small settlement | Agriculture         |
| Town              | Medium           | Trade & services    |
| City              | Large            | Industry & services |
| Metropolitan city | Very large       | Multiple functions  |


---


# 3. Rural vs Urban Settlements


### Key Differences


| Feature            | Rural Settlement                           | Urban Settlement                |
| ------------------ | ------------------------------------------ | ------------------------------- |
| Economic base      | Primary activities (agriculture, forestry) | Secondary & tertiary activities |
| Population density | Low                                        | High                            |
| Settlement size    | Small                                      | Large                           |
| Social relations   | Informal and close                         | Formal                          |
| Mobility           | Low                                        | High                            |
| Infrastructure     | Limited                                    | Developed                       |


Important Concept:


**Rural–Urban Linkage**


```plain text
Rural Areas → Food + Raw Materials
                    ↓
                Cities
                    ↓
Urban Areas → Goods + Services
```


Transport and communication networks maintain this linkage.

---


# 5. Clustered (Nucleated) Settlements


### Definition


Houses are **closely packed together** forming a compact village.


### Characteristics

- Clearly defined residential area
- Farms outside village
- Streets form **recognisable geometric patterns**

### Common Patterns

- Rectangular
- Radial
- Linear

### Regions in India

- **Northern plains**
- **Fertile alluvial plains**
- **North-East India**

### Reasons


| Factor         | Explanation                |
| -------------- | -------------------------- |
| Fertile land   | People live close together |
| Security       | Protection from attacks    |
| Water scarcity | Efficient water use        |


### Examples

- Bundelkhand region
- Rajasthan villages

Diagram:


```plain text
Clustered Settlement

   H H H H
  H H H H H
 H H H H H
   Streets
  Farms outside
```


---


# 6. Semi-Clustered Settlements


### Definition


Settlement where houses are **partially grouped** but also **somewhat separated**.


### Formation Causes

1. **Segregation of social groups**
2. **Fragmentation of large villages**
3. Expansion of clustered settlement

Typical Pattern:


```plain text
Main village
     ●●●●●
     ●●●●●

Small clusters
   ●●      ●●
```


### Social Structure


Usually:


| Area            | Community            |
| --------------- | -------------------- |
| Central village | Land owning caste    |
| Outer area      | Lower strata workers |


### Regions

- **Gujarat plains**
- **Rajasthan**

---


# 7. Hamleted Settlements


### Definition


Village divided into **several small hamlets** but sharing the same name.


Local names:


| Region      | Name  |
| ----------- | ----- |
| UP/Bihar    | Nagla |
| Rajasthan   | Dhani |
| South India | Palli |
| Bengal      | Para  |


### Causes

- **Social factors**
- **Ethnic divisions**

### Regions

- **Middle & Lower Ganga Plains**
- **Chhattisgarh**
- **Lower Himalayan valleys**

UPPCS Important Example


➡ Western Uttar Pradesh villages with **“Nagla”** settlements.


Diagram:


```plain text
Hamleted Settlement

 Nagla 1       Nagla 2
   ●●●           ●●●

      Main village name
```

# 8. Dispersed (Isolated) Settlements


### Definition


Houses are **scattered over a large area**.


### Features

- Isolated huts
- Large distance between houses
- Farms located near houses

### Causes


| Factor                 | Explanation       |
| ---------------------- | ----------------- |
| Rugged terrain         | Hills and forests |
| Fragmented land        | Small patches     |
| Low population density | Less clustering   |


### Regions in India

- Meghalaya
- Uttarakhand
- Himachal Pradesh
- Kerala

  ●        ●

# 11. Urbanisation in India


### Definition


Urbanisation = **Percentage of urban population to total population**


India’s urbanisation level in **2001 = 28%**.


Compared to developed countries → **Low urbanisation level**


---


## Trend of Urbanisation (1901-2001)


| Year | Urban population (%) |
| ---- | -------------------- |
| 1901 | 10.84                |
| 1951 | 17.29                |
| 1981 | 23.34                |
| 2001 | 27.78                |


Key observation


➡ Urban population increased **11 times during 20th century**.


---


# 12. Classification of Towns by Population


Census classifies towns into **6 classes**.


| Class     | Population    |
| --------- | ------------- |
| Class I   | > 100,000     |
| Class II  | 50,000–99,999 |
| Class III | 20,000–49,999 |
| Class IV  | 10,000–19,999 |
| Class V   | 5,000–9,999   |
| Class VI  | < 5,000       |


Important facts

- **61% urban population lives in Class I towns**
- Cities with **>1 million population = Metropolitan cities**
- Cities with **>5 million population = Mega cities**

---


# 13. Urban Agglomeration


### Definition


A **continuous urban spread** consisting of a town and its adjoining urban areas.


Possible combinations

1. Town + urban outgrowths
2. Two or more contiguous towns
3. City + adjoining towns

Examples of Urban Outgrowth

- Railway colonies
- University campus
- Military cantonment
- Port area
