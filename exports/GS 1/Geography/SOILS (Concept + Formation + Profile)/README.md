
## 1. Importance of Soil


**Soil** is the **uppermost layer of the Earth's crust** where plants grow.


### Definition


**Soil:**


A **mixture of mineral particles, organic matter, water and air** formed through weathering of rocks.

> Soil is the mixture of rock debris and organic materials that develop on the earth's surface.

### Importance of Soil

- Supports **vegetation**
- Basis of **agriculture**
- Source of **food, fibre and raw materials**
- Habitat for **microorganisms**
- Controls **water storage and nutrient cycling**

### For UPPCS Mains


**Soil is important because:**

1. Agricultural productivity
2. Ecosystem functioning
3. Nutrient cycling
4. Water filtration
5. Human settlement patterns

---


# 2. Components of Soil


| Component             | Description                   |
| --------------------- | ----------------------------- |
| **Mineral particles** | Weathered rock fragments      |
| **Humus**             | Decomposed organic matter     |
| **Water**             | Dissolves nutrients           |
| **Air**               | Required for root respiration |


Typical composition:


| Component      | Approx % |
| -------------- | -------- |
| Mineral matter | 45%      |
| Organic matter | 5%       |
| Water          | 25%      |
| Air            | 25%      |


---


# 3. Soil Formation (Pedogenesis)


### Soil formation process


```plain text
Parent Rock
      ↓
Weathering (physical + chemical + biological)
      ↓
Rock fragments
      ↓
Organic matter added
      ↓
Soil formation
```


---


## Factors Affecting Soil Formation


Remember **CLORPT** model.


| Factor                  | Role                |
| ----------------------- | ------------------- |
| **Climate**             | Weathering rate     |
| **Relief (Topography)** | Erosion & drainage  |
| **Organisms**           | Add humus           |
| **Parent rock**         | Mineral composition |
| **Time**                | Soil maturity       |


NCERT also includes **human activities** affecting soil formation.


### Human impacts

- Agriculture
- Deforestation
- Irrigation
- Industrial pollution

# 4. Soil Profile


If we **dig vertically in soil**, different layers appear.


These layers are called **Soil Horizons**.


### Soil Profile Diagram


```plain text
Surface
│
│  O Horizon → Organic matter (humus)
│
│  A Horizon → Topsoil (fertile)
│
│  B Horizon → Subsoil (minerals accumulate)
│
│  C Horizon → Weathered parent rock
│
│  Bedrock
```


 soil horizons form the **soil profile**.


---


## Important Soil Horizons


### 1️⃣ A Horizon (Topsoil)


Characteristics

- Rich in **humus**
- Contains **nutrients**
- Supports **plant growth**

Most fertile layer.


---


### 2️⃣ B Horizon (Subsoil)


Characteristics

- Mineral accumulation
- Less organic matter
- More compact

---


### 3️⃣ C Horizon


Characteristics

- Weathered parent material
- Little biological activity

---


### Soil Profile Summary Table


| Horizon | Name            | Features             |
| ------- | --------------- | -------------------- |
| O       | Organic layer   | Humus                |
| A       | Topsoil         | Fertile              |
| B       | Subsoil         | Mineral accumulation |
| C       | Parent material | Weathered rock       |

# 1️⃣ Alluvial Soil (Most Important Soil of India)

**Alluvial soil** is soil deposited by **rivers and streams through transportation and deposition of sediments**.

# 4️⃣ Laterite Soil


### Meaning


The term **Laterite** comes from the **Latin word “Later” meaning brick**.


Reason: when dry, this soil **hardens like brick**.


---


## Formation


Laterite soil forms due to **intense leaching** under:

- **High temperature**
- **Heavy rainfall**

During heavy rainfall:

- **Silica and lime are washed away**
- **Iron and aluminium oxides remain**

This process is called:


### Laterization


```plain text
Heavy Rainfall
      ↓
Leaching of silica and lime
      ↓
Iron + Aluminium accumulation
      ↓
Laterite soil formation
```


---


## Distribution


Mainly found in **high rainfall regions of peninsular India**.


### States


| State          | Regions         |
| -------------- | --------------- |
| Karnataka      | Western Ghats   |
| Kerala         | Coastal plateau |
| Tamil Nadu     | Uplands         |
| Madhya Pradesh | Plateau         |
| Odisha         | Eastern Ghats   |
| Assam          | Hills           |


Laterite soils occur mostly in **higher areas of the Peninsular Plateau**.
