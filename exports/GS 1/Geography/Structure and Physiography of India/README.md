# 1. GEOMORPHIC FORCES SHAPING INDIA


## Definition


**Geomorphic processes** = Processes responsible for shaping the **Earth’s surface landforms**.


### Two Major Types


| Type                 | Meaning                                 | Examples                                |
| -------------------- | --------------------------------------- | --------------------------------------- |
| **Endogenic Forces** | Forces originating **inside the Earth** | Plate tectonics, volcanism, earthquakes |
| **Exogenic Forces**  | Forces acting **on Earth's surface**    | Weathering, erosion, deposition         |


### Key Concept (Exam Point)


```plain text
Endogenic forces → create relief
Exogenic forces → modify relief
```


India’s landforms are the result of **interaction between these two forces**.


---


# 2. PLATE TECTONICS AND ORIGIN OF INDIA


## Movement of Indian Plate


Originally the **Indian Plate was located south of the equator** and was part of the **Gondwana landmass**.


### Geological Evolution


```plain text
Gondwana Supercontinent
        ↓
Breakup (~200 million years ago)
        ↓
Indian Plate moves northward
        ↓
Collision with Eurasian Plate
        ↓
Formation of Himalayas
```


### Important Fact


The **Indian Plate is still moving northward**, causing:

- earthquakes
- uplift of Himalayas
- tectonic instability

# 3. GEOLOGICAL DIVISIONS OF INDIA


India’s geological structure can be divided into **three major divisions**:


| Division                            | Nature                  |
| ----------------------------------- | ----------------------- |
| **Peninsular Block**                | Ancient stable landmass |
| **Himalayas and other mountains**   | Young fold mountains    |
| **Indo-Gangetic-Brahmaputra Plain** | Recent alluvial plain   |


These divisions correspond to India’s major **physiographic features**.

- **Granite**
- **Gneiss**

These rocks are **among the oldest in the world**.


### Geological Age


Stable since **Cambrian Period (~570 million years ago)**.

# 1. STRUCTURAL DIVISION OF THE HIMALAYAS


The **Himalayan Mountain System** consists of **three parallel ranges** running west → east.


## Map: Himalayan Structural Divisions


---


## 1.1 Greater Himalayas (Himadri)


| Feature    | Description              |
| ---------- | ------------------------ |
| Height     | Avg. 6000 m              |
| Nature     | Most continuous range    |
| Snow cover | Permanently snow covered |
| Glaciers   | Source of major rivers   |


### Important Peaks


| Peak          | Height |
| ------------- | ------ |
| Mount Everest | 8848 m |
| Kanchenjunga  | 8586 m |
| Nanda Devi    | 7816 m |


### Rivers Originating

- Indus
- Ganga
- Brahmaputra

---


## 1.2 Lesser Himalayas (Himachal)


Located **south of Himadri**.


| Feature   | Description             |
| --------- | ----------------------- |
| Height    | 3500–4500 m             |
| Structure | Highly compressed rocks |
| Valleys   | Famous hill stations    |


### Important Ranges

- Pir Panjal
- Dhauladhar
- Mahabharat Range

---


### Famous Valleys


| Valley         | State    |
| -------------- | -------- |
| Kashmir Valley | J&K      |
| Kangra Valley  | Himachal |
| Kullu Valley   | Himachal |


---


## 1.3 Shiwalik (Outer Himalayas)


| Feature   | Description    |
| --------- | -------------- |
| Height    | 900–1100 m     |
| Width     | 10–50 km       |
| Formation | River deposits |


These mountains consist mainly of **unconsolidated sediments**.


---


### Important Feature


Between **Shiwalik and Himachal** lies **Doon Valleys**.


Examples:

- Dehradun
- Kotli Dun
- Patli Dun

## Formation


The Northern Plains were formed by **deposition of sediments by three river systems**:

- Indus
- Ganga
- Brahmaputra

These sediments were deposited in a **geosynclinal depression**.


---


### Size


| Feature | Measurement |
| ------- | ----------- |
| Length  | ~3200 km    |
| Width   | 150–300 km  |


---


## Regional Divisions


| Region             | Rivers            |
| ------------------ | ----------------- |
| Punjab Plains      | Indus tributaries |
| Ganga Plains       | Ganga river       |
| Brahmaputra Plains | Brahmaputra river |
