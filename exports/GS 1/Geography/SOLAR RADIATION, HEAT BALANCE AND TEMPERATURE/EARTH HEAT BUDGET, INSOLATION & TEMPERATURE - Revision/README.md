# 1. BASIC IDEA OF EARTH’S HEAT SYSTEM


### Core Principle


Earth maintains **energy balance** between incoming and outgoing radiation.


```plain text
Sun → Solar Radiation → Earth Surface
Earth Surface → Terrestrial Radiation → Atmosphere → Space
```


If incoming = outgoing → **Global temperature stability**


---


### Key Facts (Prelims)


| Concept               | Fact                  |
| --------------------- | --------------------- |
| Primary energy source | Sun                   |
| Solar radiation type  | Shortwave             |
| Earth radiation type  | Longwave              |
| Atmosphere heating    | Mainly from **below** |


---


### Important Concept


Earth receives energy but also **re-radiates energy**, preventing overheating.


---


# 2. INSOLATION (INCOMING SOLAR RADIATION)


### Definition


**Insolation = Incoming solar radiation received by Earth.**


---


### Characteristics


| Feature              | Description           |
| -------------------- | --------------------- |
| Type                 | Shortwave radiation   |
| Source               | Sun                   |
| Avg. energy received | **~1.94 cal/cm²/min** |
| Distribution         | Uneven                |


Important: **Earth receives only a tiny fraction of Sun's energy.**


---


# 3. EARTH–SUN DISTANCE & INSOLATION


Earth’s orbit is **elliptical**, causing slight variation in solar energy.


| Position | Date          | Distance        | Term           |
| -------- | ------------- | --------------- | -------------- |
| Closest  | **3 January** | ~147 million km | **Perihelion** |
| Farthest | **4 July**    | ~152 million km | **Aphelion**   |


### Important Insight


Although Earth is **closer in January**, it does **not cause summer**.


Reason:

- Land–water distribution
- Atmospheric circulation

---


# 4. FACTORS CONTROLLING INSOLATION


### 1. Earth’s Rotation

- Causes **day and night**
- Insolation varies throughout the day.

---


### 2. Angle of Sun’s Rays


| Ray Type      | Energy Received |
| ------------- | --------------- |
| Vertical rays | High            |
| Slanting rays | Low             |


Reason:


Slanting rays spread over **larger area**.


---


### 3. Length of Day


| Season | Effect                      |
| ------ | --------------------------- |
| Summer | Longer days → More heating  |
| Winter | Shorter days → Less heating |


---


### 4. Transparency of Atmosphere


Solar radiation reduced by:

- **Absorption**
- **Scattering**
- **Reflection**

Agents:

- Dust
- Clouds
- Water vapour

---


### 5. Aspect of Slope


Slope direction affects heating.


| Hemisphere | Warmer slope |
| ---------- | ------------ |

| Southern   | North-facing |

## 2. Scattering

| Phenomenon | Cause      |

---


## 3. Reflection


Reflected by:

- Clouds
- Ice

# HEATING & COOLING OF ATMOSPHERE


Important concept:


**Atmosphere is heated indirectly by Earth.**


```plain text
Sun → heats land
Land → emits longwave radiation
Atmosphere → absorbs heat
```


---


# 1. CONDUCTION


### Definition


Heat transfer through **direct contact**.


Example:


Ground heats air touching it.


```plain text
Hot surface
↓
Air heated
↓
Heat spreads upward
```


---


### Characteristics


| Feature    | Detail                |
| ---------- | --------------------- |
| Type       | Direct contact        |
| Efficiency | Weak in atmosphere    |
| Reason     | Air is poor conductor |


---


# 2. CONVECTION


### Definition


**Vertical transfer of heat through air movement.**


---


### Process


```plain text
Surface heating
↓
Air becomes lighter
↓
Air rises
↓
Cool air descends
```


Creates **convection currents**.


---


### Occurs Mainly In


**Troposphere**


Examples:

- Thunderstorms
- Cumulonimbus clouds

---


# 3. ADVECTION


### Definition


**Horizontal transfer of heat via wind movement**


---


### Example


Hot desert winds → nearby regions.


Indian example:


**Loo Winds**


Affected states:

- Uttar Pradesh
- Rajasthan
- Haryana
- Delhi

---


### Comparison


| Process    | Direction  |
| ---------- | ---------- |
| Convection | Vertical   |
| Advection  | Horizontal |


---

# EARTH’S HEAT BUDGET


### Definition


Balance between:


**Incoming solar radiation**


and


**Outgoing terrestrial radiation**


---


# HEAT BUDGET BREAKDOWN


From **100 units solar radiation**


### Reflected


| Source                | Units  |
| --------------------- | ------ |
| Clouds                | 27     |
| Snow & Ice            | 2      |
| Atmosphere scattering | 6      |
| Total                 | **35** |


This reflection is **Albedo**.


---


### Absorbed


| Location      | Units  |
| ------------- | ------ |
| Atmosphere    | 14     |
| Earth surface | 51     |
| Total         | **65** |


---


### Outgoing Radiation


| Process                   | Units |
| ------------------------- | ----- |
| Direct radiation to space | 17    |
| Absorbed by atmosphere    | 34    |


Atmosphere sends **48 units back to space**.


---


# HEAT BUDGET FLOW


```plain text
100 Solar units
      ↓
35 reflected (Albedo)
      ↓
65 absorbed
     ↓
Atmosphere (14) + Surface (51)
```

# FACTORS CONTROLLING TEMPERATURE

1. Latitude
2. Altitude
3. Distance from sea
4. Ocean currents
5. Winds
6. Cloud cover
7. Slope/aspect

---


# 1. LATITUDE EFFECT


Temperature decreases from:


**Equator → Poles**


Reason:


Sun rays become **more slanting**.


---


| Region        | Temperature |
| ------------- | ----------- |
| Equator       | High        |
| Mid-latitudes | Moderate    |
| Poles         | Low         |


---


# 2. ALTITUDE EFFECT


### Environmental Lapse Rate


**6.5°C decrease per 1000 m**


Example:


| City   | Temperature |
| ------ | ----------- |
| Delhi  | Hot         |
| Shimla | Cool        |


---


# 3. DISTANCE FROM SEA


Land heats faster than water.


| Region   | Climate |
| -------- | ------- |
| Coastal  | Equable |
| Interior | Extreme |


Examples:


| Coastal | Interior |
| ------- | -------- |
| Mumbai  | Delhi    |
| Chennai | Nagpur   |


---


# 4. OCEAN CURRENTS


Warm currents increase temperature.


Example:

- **Gulf Stream → warms Europe**

Cold currents decrease temperature.


Example:

- **Peru Current**

---


# 5. PREVAILING WINDS


Carry temperature of origin region.


Examples:


| Wind origin | Effect  |
| ----------- | ------- |
| Polar       | Cooling |
| Tropical    | Warming |


Example in India:


**Loo winds**


---


# 6. CLOUD COVER


| Time  | Effect  |
| ----- | ------- |
| Day   | Cooling |
| Night | Warming |


Clouds act like **blanket**.


---


# 7. SLOPE & ASPECT

| Southern   | North-facing |
