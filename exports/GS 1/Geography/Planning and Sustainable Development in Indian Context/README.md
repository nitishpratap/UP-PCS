# 1. Meaning of Planning


### Definition


**Planning** = A **systematic process** of

- Thinking
- Formulating schemes/programmes
- Implementing actions

    to achieve **economic development goals**.


### Key Features

- **Future-oriented**
- **Goal-driven**
- **Organized decision making**
- Opposite of **hit-and-miss development**

### In Indian Context

- India adopted **Centralized Planning**
- Managed by **Planning Commission** (earlier)
- Planning implemented through **Five Year Plans**

---


# 2. Planning in India: Five Year Plans


| Plan                                      | Period    |
| ----------------------------------------- | --------- |
| 1st Plan                                  | 1951–1956 |
| 2nd Plan                                  | 1956–1961 |
| 3rd Plan                                  | 1961–1966 |
| **Plan Holiday**                          | 1966–1969 |
| 4th Plan                                  | 1969–1974 |
| 5th Plan                                  | 1974–1978 |
| 6th Plan                                  | 1980–1985 |
| 7th Plan                                  | 1985–1990 |
| **Plan gap due to political instability** | 1990–1992 |
| 8th Plan                                  | 1992–1997 |
| 9th Plan                                  | 1997–2002 |
| 10th Plan                                 | 2002–2007 |


### Plan Holiday (Important for Prelims)


Caused by:

- **1965 Indo-Pakistan War**
- **Drought (1965–66 & 1966–67)**

During this period:

- **Annual Plans (Rolling Plans)** were implemented.

# 3. Approaches to Planning


Two main approaches:


```plain text
Planning
   │
   ├── Sectoral Planning
   │
   └── Regional Planning
```


---


# 3.1 Sectoral Planning


### Meaning


Planning focused on **specific economic sectors**.


### Major Sectors

- Agriculture
- Irrigation
- Manufacturing
- Power
- Construction
- Transport
- Communication
- Social Infrastructure
- Services

### Example


Green Revolution → agricultural sector planning.


---


# 3.2 Regional Planning


### Definition


Planning aimed at **reducing regional disparities**.


### Why Needed?


```plain text
Uneven development
        ↓
Regional inequality
        ↓
Need spatial perspective
        ↓
Regional Planning
```


### Objective

- Balanced regional development
- Reduce backwardness

### Example

- **Backward Regions Grant Fund**
- **Hill Area Development Programme**

---


# 4. Target Area Planning


### Meaning


Planning focused on **economically backward regions**.


### Reason


Even **resource-rich regions remain backward** due to:

- Lack of technology
- Lack of investment
- Poor infrastructure

### Major Target Area Programmes


| Programme                          | Target Area              |
| ---------------------------------- | ------------------------ |
| Command Area Development Programme | Irrigation command areas |
| Drought Prone Area Programme       | Arid & semi-arid regions |
| Desert Development Programme       | Desert regions           |
| Hill Area Development Programme    | Mountain regions         |


### Target Group Programmes


| Programme | Target Group     |
| --------- | ---------------- |
| SFDA      | Small Farmers    |
| MFDA      | Marginal Farmers |


---


# 5. Hill Area Development Programme (HADP)


### Started


**5th Five Year Plan**


### Regions Covered

- Hilly districts of **Uttar Pradesh (present Uttarakhand)**
- **Darjeeling (West Bengal)**
- **Nilgiri (Tamil Nadu)**
- **Mikir Hills & North Cachar Hills (Assam)**

### Criteria (1981 Committee)


Hill areas above **600 m elevation** treated as **backward hill areas**.


### Objectives

- Utilize **local resources**
- Improve **livelihood**

### Major Activities

- Horticulture
- Plantation agriculture
- Animal husbandry
- Poultry
- Forestry
- Village industries

---


# 6. Drought Prone Area Programme (DPAP)


### Started


**Fourth Five Year Plan**


### Objectives

- Provide **employment**
- Create **productive assets**
- Restore **ecological balance**

### Initial Focus

- Labour intensive civil works

### Later Focus

- Irrigation
- Land development
- Afforestation
- Grassland development
- Rural infrastructure

---


# Drought Prone Regions in India


Identified by **Planning Commission (1967)**.


### Major Areas


| Region                  | States                  |
| ----------------------- | ----------------------- |
| Semi-arid Rajasthan     | Rajasthan               |
| Western Plateau         | Gujarat, Madhya Pradesh |
| Deccan Plateau          | Maharashtra             |
| Rayalaseema & Telangana | Andhra Pradesh          |
| Karnataka Plateau       | Karnataka               |
| Interior Tamil Nadu     | Tamil Nadu              |


### Exception


Punjab, Haryana, North Rajasthan


→ Less drought due to **irrigation expansion**

# Tribe: Gaddi


### Characteristics

- Practise **transhumance**
- Speak **Gaddiali dialect**

### Traditional Economy

- Subsistence agriculture
- Sheep & goat rearing

---


# Development Initiatives


Started when **Gaddis were declared Scheduled Tribes**.


### Tribal Sub-Plan


Introduced in **1974**.


### Major Development Areas

- Roads
- Communications
- Education
- Healthcare
- Agriculture

---


# Impact


### Positive

- Literacy increased
- Female literacy rose from **1.88% (1971) → 42.83% (2001)**
- Improved sex ratio
- Reduced child marriage

### Economic Changes

- Increased **cash crop cultivation**
- Decline in **pastoralism**

# 8. Concept of Development


### Definition


Development = **Positive irreversible transformation of**

- Economy
- Society
- Environment

### Development is **Multidimensional**


```plain text
Development
   │
   ├ Economic growth
   ├ Social well-being
   ├ Environmental sustainability
   └ Political rights
```


---


# Evolution of Development Concept


| Period     | Meaning of Development  |
| ---------- | ----------------------- |
| Post WW-II | Economic growth         |
| 1970s      | Growth + redistribution |
| 1980s      | Social welfare          |
| Present    | Sustainable development |


---


# 9. Sustainable Development


### Definition (Brundtland Report, 1987)

> “Development that meets the needs of the present without compromising the ability of future generations to meet their own needs.”

### Report


**Our Common Future**


### Commission


**World Commission on Environment and Development (WCED)**


Chairperson:


**Gro Harlem Brundtland**


---


# Key Components of Sustainable Development


```plain text
Sustainable Development
       │
 ┌─────┼─────┐
Ecological  Social  Economic
Protection  Equity  Growth
```

# Indira Gandhi Canal Command Area


### Map Insight

---


# Basic Facts


| Feature          | Detail                  |
| ---------------- | ----------------------- |
| Earlier name     | Rajasthan Canal         |

| Designer         | Kanwar Sain             |

| Command area     | 19.63 lakh hectares     |


---


# Location


The canal flows:

- Parallel to **India-Pakistan border**
- Through **Thar Desert (Rajasthan)**

Districts served:

- Ganganagar
- Bikaner
- Jaisalmer
- Barmer
- Jodhpur
- Nagaur
- Churu

---


# Canal System Structure


Two irrigation systems:


| Type       | Description                |
| ---------- | -------------------------- |
| Flow canal | Water flows naturally      |
| Lift canal | Water lifted against slope |


---


# Stage I


Areas:

- Ganganagar
- Hanumangarh
- Northern Bikaner

**5.53 lakh hectares**


---


# Stage II

- Afforestation

### Negative


```plain text
Excess irrigation

Waterlogging
      ↓
Soil salinity
```
