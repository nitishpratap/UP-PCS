# 1. MEANING & BASIC TERMS


### 🔹 Drainage

- **Drainage = River system (main river + tributaries)**

### 🔹 Key Terminology (Prelims Gold)


| Term                         | Meaning                              |
| ---------------------------- | ------------------------------------ |
| **Drainage Basin**           | Area drained by river system         |
| **Catchment Area**           | Area from where river collects water |
| **Watershed / Water Divide** | Boundary separating basins           |
| **Tributary**                | Smaller river joining main river     |


📌 **Example:**

- **Ambala → Water divide (Indus vs Ganga basin)**

---


# 2. FACTORS AFFECTING DRAINAGE PATTERN


| Factor               | Impact                                  |
| -------------------- | --------------------------------------- |
| Geological Structure | Hard rock → straight; Soft → meandering |
| Topography           | Steep → fast; Gentle → meanders         |
| Water Flow           | High rainfall → large rivers            |
| Geological History   | Controls pattern evolution              |

# 1. Meaning of Drainage


### Definition

- **Drainage** = The **river system of an area**, consisting of a **main river and its tributaries**.

### Key Terms


| Term               | Meaning                                         |
| ------------------ | ----------------------------------------------- |
| **Drainage Basin** | Area drained by a river and its tributaries     |
| **Catchment Area** | Specific area from which a river collects water |
| **Watershed**      | Boundary separating two drainage basins         |
| **Tributary**      | Smaller river joining a larger river            |
| **Water Divide**   | Elevated land separating two drainage basins    |


📌 **Example**

- **Ambala region** acts as a **water divide** between:
    - Indus River system
    - Ganga River system

📌 From the chapter:


A river drains water from a **specific area called catchment area**, and the **area drained by the river system is the drainage basin**.

# 2. Factors Affecting Drainage Pattern


Drainage pattern depends on:


### 1. Geological Structure

- Hard rocks → Straight channels
- Soft rocks → Meandering rivers

### 2. Topography

- Steep slopes → Fast flowing rivers
- Gentle slopes → Meandering rivers

### 3. Amount of Water Flow

- More rainfall → large rivers
- Less rainfall → seasonal streams

### 4. Geological Time Period


Drainage pattern reflects:

- rock structure
- relief
- slope
- geological history

# 1. Peninsular Drainage System


## Meaning


The **Peninsular drainage system** consists of rivers that flow over the **Peninsular Plateau of India**.


These rivers are **much older than Himalayan rivers**.


📌 The Peninsular drainage system is mainly influenced by **geological structure and slope of the plateau**.


---


# Characteristics of Peninsular Rivers


| Feature         | Explanation                   |
| --------------- | ----------------------------- |
| Older rivers    | Very old geological origin    |
| Seasonal        | Depend mainly on rainfall     |
| Fixed course    | Less chances of course change |
| Less erosion    | Gentle slopes                 |
| Shallow valleys | Compared to Himalayan rivers  |


---


# Direction of Flow


Most Peninsular rivers flow:


### **West → East**


because the **Peninsular plateau slopes eastward**.


They drain into:


### **Bay of Bengal**


Examples

- Godavari
- Krishna
- Mahanadi
- Kaveri

---


# West Flowing Rivers


Only a few rivers flow westwards.


Important ones:


| River        | Sea         |
| ------------ | ----------- |
| Narmada      | Arabian Sea |
| Tapi (Tapti) | Arabian Sea |


These rivers flow through **rift valleys**.
