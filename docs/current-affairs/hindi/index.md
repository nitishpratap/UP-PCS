# करेंट अफेयर्स (Current Affairs)

[:material-translate: English Version (अंग्रेजी संस्करण)](../index.md){ .md-button }

---

यह UPPCS प्रारंभिक परीक्षा के लिए **जीवित करेंट अफेयर्स डेस्क** है। स्टेटिक जीएस विषय नोट्स में रहता है; सीए का वजन, तथ्य पढ़ना और मासिक अपडेट यहां रहते हैं।

इसे तीन स्थितियों में प्रयोग करें:

1. **सीए शुरू करने से पहले:** [2018-2025 विश्लेषण](00_Analysis_2018_2025.md) पढ़ें ताकि आप जान सकें कि प्रत्येक पत्रिका से क्या निकालना है।
2. **हर महीने:** तथ्य जांच सूचियों का उपयोग करके मेल खाने वाले [विषय पत्रक](topics/index.md) में नई खबरें डालें - कवरेज शुरू होती है **[जनवरी 2026](topics/months/2026-01.md)**।
3. **पिछले 4-6 सप्ताह:** केवल हीट-मैप विषयों + प्रथम + यूपी सीए + गलत-बयान जाल को संशोधित करें।

## पाइपलाइन (Pipeline) (आपकी योजना)

1. **विश्लेषण** - पीडीएफ + प्रतिलेख, रेपो पीवाईक्यू के साथ सामंजस्य स्थापित।
2. **मासिक पत्रक** - **जनवरी 2026** से **अक्टूबर 2026** तक लाइव (आज तक समन्वयित)।
3. **अगला:** पूर्ण CA PYQ बैंक; फिर नवंबर 2026 मासिक सिंक।
4. **लक्ष्य:** सीए पर दृष्टिकोण **~90% सही** केवल वही पढ़कर होता है जो यूपीपीसीएस वास्तव में परीक्षण करता है।
