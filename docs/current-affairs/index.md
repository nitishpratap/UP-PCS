# Current Affairs

This is the **living Current Affairs desk** for UPPCS Prelims. Static GS stays in Subject Notes; CA weight, reading facts, and monthly updates live here.

Use it in three situations:

1. **Before starting CA:** read the [2018–2025 analysis](00_Analysis_2018_2025.md) so you know what to extract from every magazine.
2. **Every month:** drop new news into the matching [topic sheet](topics/index.md) using the fact checklists — coverage starts **[January 2026](topics/months/2026-01.md)**.
3. **Last 4–6 weeks:** revise only heat-map topics + Firsts + UP CA + false-statement traps.

---

## Why CA gets its own section

| Fact (2018–2025 tagged set) | What it means |
|-----------------------------|----------------|
| **~245–255** functional CA questions in eight papers | Roughly **26–39** every year (Civils ~245; repo functional ~255) |
| Repo `Subject: Current Affairs` alone = **161** | Too low — especially 2024 (**9**) and 2025 (**13**) |
| **7 topics ≈ 70%** of CA | International, Schemes, Science–Defence, Awards, Environment, National, Indices |
| 2024–25 = statement machine | Read for the **false second sentence**, not only the headline |
