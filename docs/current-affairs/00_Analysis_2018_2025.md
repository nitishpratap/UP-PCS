# Current Affairs — UPPCS Prelims Analysis (2018–2025)

> **Sources:** Civils Campus CA Analysis PDF + YouTube strategy transcript (Aug 2026), reconciled against repo `pyq/2018`–`pyq/2025`.
> **Working load for prep:** **~245–255 functional CA questions** (~26–39/year) — not the narrow Subject tag alone.
> **Next step:** build monthly topic sheets under [Monthly Topics](topics/index.md).

## Decision

Current Affairs is a **mark bank + leveler**, not a side magazine.

| What the data says | Revision decision |
|--------------------|-------------------|
| **~30 functional CA questions** most years | Treat CA like a full subject, not “last week reading”. |
| History static often yields **~20–25**; one good CA magazine + revision can target **~20–27** correct | ROI is higher than thick static books if you read with key facts. |
| Freshers and repeaters start equal on CA | Freshers should not postpone CA for “static first”. |
| **7 topics ≈ 70%** of functional CA | Build monthly notes only on the heat map first. |

!!! tip "Target for 90% CA accuracy"
 Do not read “everything in the magazine”. Read every item through the **fact checklist** below. If a news item has no fact (publisher / venue / first / false second sentence / beneficiary number), skip or park it.

## Format Shift (what traps look like)

| Era | Paper feel | How they wrong-foot you |
|-----|------------|-------------------------|
| 2018–21 | Mixed one-liners + some statements | Wrong city, wrong year, wrong publisher |
| **2022–25** | **Statement machine** (esp. 2024–25) | One of two statements is deliberately false |
| First / Records | Stable | First sentence true; **second sentence** (city / range / payload) false |
| Match List | Rising | Head of state ↔ country; Day ↔ date; Book ↔ author; Scheme ↔ year |

** logic to plant in every monthly note:** “Which fact would examiner flip to make Statement 2 false?”

## How to Read Each Dimension (fact checklist)

Use this when scanning any monthly magazine. If you cannot fill the facts, the item is low-yield for UPPCS.

### 1. Indices / rankings (~1–4/year historically)

| Fact | Ask |
|------|-----|
| Publisher | Who releases it? |
| Parameters | What is counted / excluded? |
| Top 3 | Global or Indian top ranks |
| India’s rank | Exact or band |
| Findings | One headline finding for India / region |
| State angle | Top state / UP category (Performer, Aspirant, etc.) |

Treat **indices and reports as one family**. Example pattern: World Population Report → **UNFPA**; TTCI → **WEF**.

### 2. Reports / statistics

| Fact | Ask |
|------|-----|
| Agency | Who published? |
| One number | %, rank, TFR, share |
| Static mix | Replacement-level TFR 2.1 type traps |

### 3. First / largest / records

Any “first woman / first hydrogen / first e-Lok Adalat / 100% solar UT” is auto-important.

| Fact | Ask |
|------|-----|
| What is first? | Title of the record |
| Who / where / which country? | The identity line |
| Second fact | City, material, year — this is the usual false statement |

Classic facts from PYQs: Diu 100% solar UT; UAE Hope mission; Motihari–Amlekhganj pipeline; first female WTO DG (Nigeria); Janet Yellen (US Treasury).

### 4. International — largest regular block (~22%)

Four repeating stems:

1. **Summits:** host country/city + edition + India representation (PM / President / EAM) + outcome / pact (binding or not).
2. **Foreign elections / leaders:** new PM/President; Indian-origin mayor/leader is high alert.
3. **Bilateral with neighbours (Nepal, Bhutan, Bangladesh) + extended neighbourhood:** joint projects, pipelines, buses, hydro, ports, FTAs, UPI deals.
4. **Org HQ / heads:** ISA Gurugram; IMF MD; WTO DG; “NOT a member” traps (GCC, BIMSTEC, G7 invitees).

**FTA extra facts:** partners, duty-free share, exception list, timeline.

### 5. National events / institutions / infrastructure

| Pattern | What they ask |
|---------|----------------|
| Location | Institute, tunnel, bridge, museum, fair, secretariat |
| Statements | Correct / incorrect on theme, agency, feature |
| Match | Day ↔ event; institute ↔ place |
| Who / when | Signatory, developer, executing agency |
| State CA | New policy, election, appointment, resource find |

### 6. Awards (~8%; hot in 2025)

| Fact | Ask |
|------|-----|
| Winner | Name |
| Field / work | Why awarded |
| Edition / venue | nth edition, host city |
| Giver | Body / country |
| India angle | Indian winner or PM civilian honour abroad |

Cover Nobel, Booker, Oscar, Pulitzer, Ramon Magsaysay, plus national: Padma, Khel Ratna, Arjuna, Vigyan Ratna, Sahitya Akademi, Jnanpith. UN / UNESCO awards are priority.

### 7. Sports (thin lately)

Host, edition, motto, brand ambassador, India’s medals / rank, winner vs runner-up, **incorrect medal-colour pairs**. Olympics / Asian Games / World Cups still matter when they fall in the window; 2023–25 tagged sports were quiet.

### 8. Government schemes (~13%)

| Fact | Ask |
|------|-----|
| Start year / end year / tenure | Period traps (NIP 2020–25 vs 2020–30) |
| Ministry / Nodal body | NITI vs ministry |
| Beneficiaries + exclusions | Who is in / out |
| Target number / DBT amount | ₹6000, 1 crore households, etc. |
| Allocation | Budget line if announced |
| Rename | Mid-Day Meal → PM POSHAN type |

Favourite formats: find incorrect statement; only Statement 1 correct; Match scheme ↔ year; A/R on period or objective.

### 9. Uttar Pradesh CA

Major initiative in the last ~12 months; unique infrastructure; UP rank in national indices; new Ramsar; defence/hydrogen/fertiliser plant; FDI rank; crop/milk leadership; ODOP; SDG progress.

Known PYQ cluster: Purvanchal Expressway (route trap), Noida Charkha, UP SDG = Performer, HRIDAY = Varanasi + Mathura, Kushinagar international airport, Ramsar sites, aspirational districts count, **2025:** UP Ramsar, ODOP, UP SDG Progress Report.

**Repo rule:** search Environment + Economy + Subject `Uttar Pradesh` + Current Affairs — not UP Subject alone.

### 10. Science / Space / Defence (rising)

| Space | Defence |
|-------|---------|
| Mission date, target body, agency, rocket, vehicle | Missile name, range, partner country |
| Arrival / outcome | Indigenous platform (UAV, bomber, sub, helo) |
| Private space startup novelty | Exercise name (bilateral/multilateral), participants |
| ISRO PSLV/GSLV flights | Procurement from which country; Project 75/75I style |

### 11. Health

Disease-free declarations; new vaccines; rare-disease outbreaks (where + cause); WHO declarations; Ayurveda / traditional medicine centres (e.g. Jamnagar).

### 12. Books / personalities

~1 book–author stem most years; award-winning books first. Appointments: CDS, SEBI, Speakers, Governors, Assembly Speakers (Match List). Indian-origin abroad = instant attention.

### 13. Economy / budget / trade

Union Budget + Economic Survey + UP Budget/Survey; GDP/GNP snapshots; MSP; core industries; WPI/CPI (base year, agency, frequency); FDI source/sector/state; NSO / RBI reports (LFPR, FSR); FTA/trade diversification.

### 14. Environment / days

Summit / declaration / award; Mission LiFE; Project Cheetah; Operation Olivia; Net-Zero ≠ zero emissions; Day ↔ theme match; India GHG rank; species–state pairs.

### 15. Judiciary / constitution (rare CA)

Hot SC judgments, recent amendments, major legislation name + date + object — only when the news is loud.

## Sources Strategy (from transcript + practical merge)

| Approach | Sources | When to use |
|----------|---------|-------------|
| Yearly consolidation | Vision IAS PT 365 / Drishti; Ghatna Chakra / Ghatna Saar | If starting late (≤3 months to prelims), pick **one** yearly + revise hard |
| Monthly | Chronicle / Pratiyogita Darpan / Drishti monthly | Best for continuous coverage + monthly topic updates |
| Gap-fill | Multi-source short notes (Civils Campus CA PDF style) | After primary source — catches the **~10–15%** that one magazine misses |

**Practical rule for this site:** pick **one primary monthly**, update the topic files here every month, then once before prelims do a yearly consolidation pass using the same fact checklists.

Overlap between Vision and Ghatna-type yearlies is roughly **85–90%**. The remaining **10%** is where wrong options often hide — hence a second short pass.

## Must-Score Reading Order (weekly)

1. **International** (summits this month + neighbour bilateral + org heads).
2. **Schemes** (new / renamed / budgeted) with tenure + beneficiary facts.
3. **Science–Space–Defence** (ISRO + missile/exercise + indigenous kit).
4. **Awards + Environment/Days + National infra**.
5. **Indices/Reports** (publisher + India/UP rank).
6. **Firsts**, Economy/Budget, Books, Appointments, Health.
7. **UP CA** sheet — every major state news with place / rank / scheme fact.

## Mock Audit (after every CA mock)

- Missed because **publisher / venue / edition** was wrong?
- Fell for **true Statement 1 + false Statement 2**?
- Confused **member vs non-member** of a grouping?
- Skipped a **first / Indian-origin / PM honour** item?
- Scheme error on **year, ministry, or beneficiary number**?
- UP item lost on **route / city / Ramsar / rank category**?

If the same audit line repeats twice, that dimension’s monthly file is incomplete.
