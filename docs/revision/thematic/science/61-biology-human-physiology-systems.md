## 📖 Thematic Revision Summary (Reformatted from PDF)

### Digestive System (पाचन तंत्र)

| Organ | Function |
|-------|---------|
| Mouth | Digestion of carbohydrates begins; enzyme: Salivary Amylase / Ptyalin |
| Stomach (आमाशय) | Secretes Pepsin (proteins) & Renin (milk); acidic (HCl) |
| Small Intestine (छोटी आंत) | Complete digestion + absorption via microvilli |
| Liver (यकृत) | Largest gland; secretes Bile juice (stored in Gallbladder); emulsifies fats |

### Circulatory System (परिसंचरण तंत्र)

**Blood Composition:**
- Plasma (प्लाज्मा): Liquid part (~55%)
- **RBCs** (Erythrocytes): Contain Haemoglobin; lifespan 120 days; made in bone marrow; destroyed in Spleen
- **WBCs** (Leukocytes): Defense/immunity; lifespan 2–4 days
- **Platelets** (Thrombocytes): Blood clotting (aided by Vitamin K)

**Blood Groups:**
- Discovered by: Karl Landsteiner
- Universal Donor: O negative (O⁻)
- Universal Acceptor: AB positive (AB⁺)

### Excretory & Nervous Systems

| System | Key Facts |
|--------|----------|
| Kidney | Functional unit: Nephron; filters urea from blood |
| Brain | Functional unit: Neuron |
| Cerebrum | Largest part; seat of intelligence, memory, consciousness |
| Hypothalamus | Regulates temperature, hunger, thirst, emotions |
| Medulla Oblongata | Controls involuntary actions (heartbeat, respiration, BP) |

**Examiner Traps:**
- Liver is largest GLAND; Skin is largest ORGAN
- Spleen = "Graveyard of RBCs" (where old RBCs are destroyed)
- Universal Donor = O⁻ (negative); Universal Acceptor = AB⁺ (positive)
- Vitamin K → blood clotting; Vitamin C → prevents scurvy
