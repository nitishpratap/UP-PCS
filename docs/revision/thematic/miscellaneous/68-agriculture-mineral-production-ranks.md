## 📖 Thematic Revision Summary (Reformatted from PDF)

### Crop Production Leadership (India)

| Crop | Leading State |
|------|--------------|
| Wheat (गेहूँ) | Uttar Pradesh |
| Sugarcane (गन्ना) | Uttar Pradesh |
| Potato (आलू) | Uttar Pradesh |
| Milk (दूध) | Uttar Pradesh |
| Rice (चावल) | West Bengal |
| Total Pulses & Soybean | Madhya Pradesh |
| Coarse Cereals & Mustard | Rajasthan |
| Cotton (कपास) | Gujarat / Maharashtra |
| Coffee (कॉफी) | Karnataka |
| Tea (चाय) | Assam |
| Rubber | Kerala |
| Spices | Andhra Pradesh |
| Mentha / Mint | Uttar Pradesh (world's largest too) |

### Mineral Reserves & Production (Leading State)

| Mineral | Leading State |
|---------|--------------|
| Coal | Chhattisgarh / Odisha |
| Iron Ore | Odisha |
| Bauxite & Chromite | Odisha |
| Copper | Madhya Pradesh (Malanjkhand) |
| Mica | Jharkhand |
| Manganese | Odisha |
| Limestone | Andhra Pradesh / Rajasthan |
| Uranium | Jharkhand (Jaduguda) |
| Gold | Karnataka (Kolar Gold Fields — KGF) |
| Diamonds | Madhya Pradesh (Panna) |

**Examiner Traps:**
- UP is No. 1 in Wheat, Sugarcane, Potato, Milk (all 4)
- UP is also world's largest Mentha producer (Barabanki)
- Odisha = multiple minerals (Iron ore, Bauxite, Chromite, Manganese)
- Panna (MP) = India's only significant diamond mining area

## ❓ Previous Years Questions (UPPCS Prelims)


**Q1.** Match List-I (Mineral) with List-II (Top Producing State in India):
| List-I | List-II |
| :--- | :--- |
| A. Bauxite | 1. Madhya Pradesh |
| B. Copper | 2. Odisha |
| C. Gold | 3. Chhattisgarh |
| D. Coal | 4. Karnataka |

A. A-2, B-1, C-4, D-3  
B. A-1, B-2, C-3, D-4  
C. A-2, B-3, C-4, D-1  
D. A-4, B-1, C-2, D-3  

<details>
<summary>Show answer</summary>
**Ans: A.** Bauxite (Odisha), Copper (MP), Gold (Karnataka), Coal (Chhattisgarh). Note: Coal reserves are highest in Jharkhand, but production is highest in Chhattisgarh/Odisha depending on the reporting year. UP/UKPCS traditionally accepts Chhattisgarh / Odisha as top producer and Jharkhand as top reserve.
</details>

A. Punjab  
B. Madhya Pradesh  
C. Uttar Pradesh  
D. Maharashtra  

<details>
<summary>Show answer</summary>
**Ans: C.** Uttar Pradesh holds the #1 spot in Wheat, Sugarcane, Potato, and Total Foodgrains.

B. Australia
