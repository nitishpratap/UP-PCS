## 📖 Core Thematic Revision (PCS Matrix Complete Notes)

### Geography & Boundaries (भौगोलिक सिीमाएँ):
- Bordering States & UTs (सीमावतर्वी राज्य): 8 States + 1 UT (Delhi) + 1 Country (Nepal).
- Southernmost District (दक्षिणतम ɣज़ला): Sonbhadra (Borders 4 states: Madhya Pradesh,
- Chhattisgarh, Jharkhand, Bihar).
- Extreme Points (भौगोलिक सिीमांति ɣज़िले):
- Westernmost (पशि्चिमी): Shamli
- Easternmost (पूवर्वी): Ballia
- Northernmost (उत्तरी): Saharanpur
- Forest & Tree Cover (वनावरण): Sonbhadra has the highest forest area; Bhadohi (Sant Ravidas
- Nagar) has the lowest forest area.

### State Symbols (राज्य प्रतिीक):
- State Animal (राज्य पशु): Swamp Deer / Barasingha (बारहसिंगा)
- State Bird (राज्य पक्षिी): Sarus Crane (सारस / क्रौंच)
- State Tree (राज्य वृक्षि): Ashok Tree (अशोक)
- State Flower (राज्य पुष्प): Palash / Flame of the Forest (पलाश / ढाक)
- State Fish (राज्य मछली): Chitala (चितला)
