## 3. Five patterns UPPCS likes

1. **Match the physical feature to the state or country.** Peaks, passes, deserts, currents.
2. **River system codes.** Tributary, origin, east- vs west-flowing, UP stretch.
3. **Climate Assertion–Reason.** One true physical fact plus a false zonal explanation (2025 Australia: interior is arid, but northern Australia is **not** temperate).
4. **Minerals and energy.** “Largest / leading / not found in” statements.
5. **UP negative geography.** Expressway, river, or sanctuary **not** in the listed district.

---

## 4. Format shift

Direct one-liners still appear, but **2023–2025** add Assertion–Reason and multi-statement on world and climate. Drainage and minerals stay Match-List heavy.

---

## 5. Master trap checklist

| Trap | Correct lock |
|------|----------------|
| Northern Australia is temperate | It is largely **tropical** |
| All west-flowing peninsular rivers are short and drain to the Arabian Sea only as a memory dump | Learn **Narmada, Tapi, Mahi, Sabarmati** as the exam set, plus exceptions taught in Topic 3 |
| Highest peak in India is K2 for “India” questions | **K2 is in PoK**; many papers want **Kangchenjunga** for India proper — read the stem |
| Monsoon is only the Bay of Bengal branch | Arabian Sea branch is equally testable |
| UP is only a Ganga-plain question | Bundelkhand, Terai, plateau edges, and expressways are asked |
| Ocean currents can be guessed from colour on a cheap map | Revise warm vs cold pairs in Topic 16 |
