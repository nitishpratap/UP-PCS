## Memory Tricks

- **Kilimanjaro is African. Fuji / Pinatubo / St Helens are Pacific.**
- **Pyrenees = Spain–France. Italy = Apennine. Bulgaria = Balkan.**
- **Gobi = Mongolia + China only.**
- **Gibson lives in Australia. Pampas live in Argentina.**
- **Maquis–Med, Fynbos–Cape, Chaparral–California, Matorral–Chile.**
- **Selva is the forest; Terra Roxa is the soil — both Brazil.**
- **Mediterranean = winter rain. Savanna = Land of Big Games.**

## N.2 Plateaus

A plateau is an **elevated tableland** — flatter than a mountain range, higher than a plain. Rivers often **dissect** it into mesas and gorges.

| Kind | Meaning | World example |
|------|---------|---------------|
| **Intermontane** | High block **between** fold ranges | **Tibet** (Himalaya–Kunlun); **Altiplano** (Andes) |
| **Piedmont** | At the **foot** of mountains | Appalachian piedmont; Patagonian edge |
| **Continental / shield** | Old worn-down block | **Deccan**, Brazilian, African, Western Australian |
| **Lava / volcanic** | Flood basalt | **Columbia** (USA), **Deccan Trap** cover |

| Plateau | Where | Exam lock |
|---------|-------|-----------|
| **Tibetan Plateau** | China / Tibet | **Highest large** plateau. Headwaters: Indus, Sutlej, Brahmaputra, Mekong, Yangtze, Hwang Ho |
| **Pamir** | Tajikistan knot | Phrase **“Roof of the world”**. Knot of Himalaya–Karakoram–Hindu Kush–Tien Shan |
| **Deccan** | Peninsular India | Old gneiss + **Deccan Trap** lava in the west. **Not** Brazil |
| **Malwa / Chotanagpur** | India | Chotanagpur = Jharkhand coal–iron table |
| **Brazilian** | Brazil | Coffee on **Terra Roxa**; iron. Separate from Andes |
| **Guiana** | Venezuela–Guyana–N Brazil | |
| **Patagonian** | S Argentina | Rain-shadow plateau east of Andes |
| **East African / Ethiopian** | Africa | Rift lakes; Blue Nile from Ethiopia |
| **African (south)** | SA / Botswana / Namibia | High veld sits on it |
| **Colorado** | SW USA | **Grand Canyon** (Colorado River) cut into it |
| **Columbia** | Washington–Oregon–Idaho | **Lava** plateau |
| **Colorado Plateau ≠ Columbia** | — | Canyon vs lava — do not swap |
| **Mexican (Mesa Central)** | Mexico | |
| **Anatolian** | Türkiye | Interior of Asia Minor |
| **Iranian** | Iran | Dasht-e-Kavir / Lut on it |
| **Mongolian** | Mongolia | **Gobi** on the dry side |
| **Altiplano** | **Bolivia–Peru** | Highest inhabited Andean plateau; Lake Titicaca |
| **Meseta** | **Spain** | Interior tableland of Iberia |
| **Loess Plateau** | N China | Wind-silt; Hwang Ho yellow colour |
| **Kimberley / Western Plateau** | Australia | Old shield |

> **Exam note:** **Tibet** = highest *large* plateau. **Pamir** = the stock phrase “Roof of the world.” Do not call the **North European Plain** a plateau.

## N.3 Plains

Plains are **low, gently rolling** lands — the world’s grain and cattle belts.

| Kind | How formed | Example |
|------|------------|---------|
| **Alluvial** | River dump | Indo-Gangetic, Nile, Mesopotamia, Hwang Ho, Mississippi |
| **Glacial / till** | Ice-sheet | North European Plain, Prairie of Canada–USA |
| **Coastal** | Sea + river | Atlantic coastal USA; eastern India |
| **Lacustrine** | Old lake floor | Imphal-type locally; some interior basins |

| Plain | Where | Exam lock |
|-------|-------|-----------|
| **Indo-Gangetic** | India–Pakistan–Bangladesh | Alluvium; wheat–rice–cane |
| **North / Great European** | France → Poland → Russia | Wheat–dairy; glacial + river |
| **Great Plains / Prairie** | USA–Canada | Temperate grassland overlay |
| **Pampas** | **Argentina** (into Uruguay) | Temperate grassland **and** a plain. **Not Chile, not Brazil** |
| **Llanos** | Orinoco (Venezuela–Colombia) | Tropical grassland plain |
| **Manchurian** | NE China | Soy / wheat |
| **West Siberian** | Russia | Ob–Yenisei lowland |
| **Mesopotamian** | Iraq | Tigris–Euphrates |
| **Nile valley / delta** | Egypt | Alluvium in a desert |
| **Po valley** | N Italy | Alpine alluvium |
| **Hungarian (Alföld)** | Hungary | **Puszta** grassland sits here |
| **Canterbury** | New Zealand | Downs / sheep |
| **Nullarbor** | S Australia | Limestone plain, not a grassland name |

Pampas vs Campos: same “open land” idea, **different country** — Argentina vs Brazil.

## N.5 Islands

**Australia is a continent**, not an island. Rank **islands** by area:

**Greenland → New Guinea → Borneo → Madagascar → Baffin → Sumatra → Honshu → Great Britain …**

| Kind | How made | Examples |
|------|----------|----------|
| **Continental** | Piece of a continent, shallow shelf | **Greenland**, **Borneo**, **New Guinea**, **Madagascar**, Britain, Sri Lanka |
| **Volcanic arc / hot-spot** | Magma | **Java**, **Iceland**, **Hawaii**, Japan (Honshu mixed arc), Sicily (Etna) |
| **Coral / atoll** | Reef on a sinking volcanic peak or shelf | Maldives, Lakshadweep, many Pacific atolls |
| **Coral reef (not an island rank)** | — | Great Barrier Reef (Australia) is a **reef**, not a “largest island” option |

| Island | Lock |
|--------|------|
| **Greenland** | **Largest island**. Denmark. Ice sheet. Inuit |
| **New Guinea** | 2nd. Split **Indonesia (Papua) + Papua New Guinea** |
| **Borneo (Kalimantan)** | 3rd. **Three countries: Indonesia, Malaysia (Sabah/Sarawak), Brunei**. **Sunda shelf** — **not** volcanic deposition (2022 **Only 1**) |
| **Madagascar** | 4th. Africa’s big island; unique fauna; **not** three-country split |
| **Baffin** | Canada / Arctic |
| **Sumatra** | Indonesia; Sunda arc **is** volcanic — contrast with Borneo |
| **Java** | Indonesia; dense, volcanic |
| **Sulawesi** | Indonesia; K-shaped |
| **Honshu** | Japan’s main island. Hokkaido / Kyushu / Shikoku = the other three |
| **Great Britain** | England–Scotland–Wales (Ireland is separate) |
| **Iceland** | Mid-Atlantic Ridge; volcanic |
| **Hawaii** | Pacific hot-spot chain |
| **Sri Lanka** | Continental; Palk Strait / Gulf of Mannar vs India |
| **Tasmania** | S of Australian mainland |
| **Sicily / Sardinia / Corsica / Crete / Cyprus** | Med islands. Sicily has **Etna** |
| **New Zealand** | North Island + South Island; Cook Strait |

**Greater Sunda:** Sumatra, Java, **Borneo**, Sulawesi. Only Borneo is the “three countries, not volcanic dump” PYQ.

> **Exam note:** Stmt 1 true, stmt 2 false for Borneo. Java/Sumatra **are** volcanic-arc; do not copy that onto Borneo.

## N.6 Deserts

| Kind | Why dry | Examples |
|------|---------|----------|
| **Hot subtropical** | Descending air ~**30°** (horse latitudes) | Sahara, Arabian, Australian, Kalahari, Thar |
| **Coastal / fog** | Cold current + stable air | **Atacama** (Peru/Humboldt), **Namib** (Benguela) |
| **Rain-shadow** | High range steals moisture | **Patagonia** (Andes), **Atacama** (Andes), Thar (Aravalli leeward) |
| **Cold interior** | Far from sea, winter freeze | **Gobi**, **Taklamakan**, Great Basin, Colorado Plateau dry side |

| Desert | Country / belt | Exam |
|--------|----------------|------|
| **Sahara** | N Africa (many states) | **Largest hot** desert. Hoggar / Tibesti are highland islands in it |
| **Arabian** | Arabian Peninsula | 2nd large hot desert. **Rubʿ al-Khali** = Empty Quarter |
| **Gobi** | **Mongolia + China** (Inner Mongolia, Gansu, Xinjiang fringe) | **Cold**. 2025: **Only 1 and 2**. **Not** Russia, **not** Kazakhstan |
| **Great Sandy** | **NW Australia** | Smallest of the 2023 four |
| **Great Victoria** | S/W Australia | Largest **Australian** desert by many lists |
| **Gibson** | **Australia** (between Victoria and Sandy) | **Not Brazil** (2018) |
| **Simpson** | Central Australia | Red dunes |
| **Sonoran** | **USA** + Mexico | 2018 correct pair. Cactus desert |
| **Mojave** | USA | Death Valley |
| **Chihuahuan** | USA–Mexico | |
| **Taklamakan** | **China** (Xinjiang) | Cold; Tarim basin. 2018 correct pair |
| **Karakum** | **Turkmenistan** | 2018 correct pair. **Not** Kazakhstan’s default dump |
| **Kyzylkum** | Uzbekistan–Kazakhstan | Red sand; separate from Karakum |
| **Kalahari** | Botswana / South Africa / Namibia | Bushman / San. Semi-desert |
| **Namib** | Namibia coast | Fog; among the oldest |
| **Atacama** | N **Chile** (into Peru) | Among the **driest** on Earth |
| **Patagonia** | **Argentina** | Cold rain-shadow. Not Chile’s Atacama |
| **Thar** | India–Pakistan | Pleistocene–recent sands |
| **Dasht-e-Lut / Kavir** | Iran | Hot interior |
| **Great Basin** | USA | Cold interior |

**2023 size ladder (smallest → largest):** Great Sandy → **Gobi** → **Arabian** → **Sahara**. Code **I, IV, II, III**.

> **Exam note:** Kazakhstan has **other** dry belts (Kyzylkum fringe, steppe). That does **not** put Gobi into option 4.

## N.9 World Climatic Regions

Pressure belts **follow the Sun**. At the **winter solstice** (NH December) they shift **south** — that is why Mediterranean west coasts get **winter** westerlies (2024 Q79 both true).

| Type (Köppen) | Where | Rain timing | Vegetation / crop |
|---------------|-------|-------------|-------------------|
| **Equatorial (Af)** | Amazon, Congo, Malaysia | **Year-round** convection | Selva; **not** a citrus belt |
| **Savanna / Sudan (Aw)** | Africa belt, Campos, Llanos, N Australia | **Summer** wet, winter dry | Grass + trees; baobab; **Land of Big Games** |
| **Tropical monsoon** | India, mainland SE Asia | **Summer** monsoon | Deciduous teak/sal |
| **Hot desert (BWh)** | Sahara, Arabia, Thar, Australia | Rare | Xerophytes |
| **Cold desert (BWk)** | Gobi, Taklamakan | Rare / snow | Sparse |
| **Steppe (BS)** | Ukraine to Mongolia; rain-shadow edges | Scanty | Short grass |
| **Mediterranean (Cs)** | **30–45° west coasts** — five patches below | **Winter** cyclonic | Olive, citrus, vine, cork, wheat, cedar, maquis |
| **China / warm-temperate east coast** | E China, SE USA, NSW, Natal | **Summer** rain | Laurel / tea hills |
| **British / W European (Cfb)** | Britain, NW France, W Norway | **Year-round** cyclonic | Deciduous oak–beech |
| **Taiga / boreal** | 50–70°N | Modest, summer max | Conifers |
| **Tundra (ET)** | Arctic coast | Low | Moss/lichen; permafrost |
| **Ice cap (EF)** | Greenland interior, Antarctica | — | None |

**Five Mediterranean patches** (all **west** coasts, not east):

1. Mediterranean Sea basin (Spain, Italy, Greece, Levant, Maghreb)
2. **California**
3. Central **Chile**
4. SW **Australia** (Perth side)
5. **Cape** / Western Cape, South Africa

**Mediterranean mechanism**

- **Summer:** subtropical **high** + **dry terrestrial winds** → drought (bright, good for citrus/vine).
- **Winter:** belts shift equatorward → **westerlies** + Mediterranean cyclones → rain.
- Do not give Mediterranean **summer** rain (that is monsoon / China type).

## Common Traps — Don't Fall For These

1. **Kilimanjaro = Ring of Fire** — FALSE. **East African Rift**.
2. **Pampas = Brazil** — FALSE. **Argentina**. Brazil = **Campos**.
3. **Gibson = Brazil** — FALSE. **Australia**.
4. **Gobi in Kazakhstan / Russia** — FALSE for the 2025 code. **Mongolia + China**.
5. **Sahara smaller than Gobi** — FALSE. Sahara is the giant.
6. **Borneo = volcanic island** — FALSE. **Sunda shelf**; three countries.
7. **Maquis = California** — FALSE. **Chaparral**. Maquis = Med basin.
8. **Fynbos = Chile** — FALSE. **South Africa**. Chile = **Matorral**.
9. **Land of Big Games = Sahara** — FALSE. **Tropical savanna**.
10. **Mediterranean rain in summer** — FALSE. **Winter**.
11. **Taiga = treeless** — FALSE. That’s **tundra**.
12. **Selva = Brazilian soil** — FALSE. Selva = **forest**; soil = **Terra Roxa**.
13. **Pyrenees = Italy** — FALSE. **Spain–France**. Italy = **Apennine**.
14. **Toubkal = Algeria** — FALSE. **Morocco**. Hoggar = Algeria.
15. **Etna = Pacific** — FALSE. **Italy / Mediterranean**.
16. **Australia = largest island** — FALSE. Australia is a **continent**; largest island = **Greenland**.
17. **Atlas = France/Spain** — FALSE. That is **Pyrenees**. Atlas peak Toubkal = **Morocco**.
18. **Pamir = highest large plateau** — FALSE. Phrase is Pamir; **Tibet** is the highest large plateau.
19. **Colorado Plateau = lava** — FALSE. **Columbia** is lava; Colorado holds the **Grand Canyon**.
20. **Aconcagua = Chile** — FALSE. **Argentina**. Chimborazo = Ecuador.
