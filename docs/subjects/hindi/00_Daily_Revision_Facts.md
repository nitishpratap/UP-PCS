### B. उपसर्ग जोड़कर बनने वाले विशिष्ट विलोम शब्द
- **'अ' उपसर्ग द्वारा:** सभ्य — असभ्य, हिंसा — अहिंसा, ग्राह्य — अग्राह्य, लौकिक — अलौकिक, नित्य — अनित्य।
- **'अप' उपसर्ग द्वारा:** मान — अपमान, कीर्ति — अपकीर्ति, यश — अपयश, शकुन — अपशकुन।
- **'अन' उपसर्ग द्वारा:** अभिज्ञ — अनभिज्ञ, आहुत — अनाहुत, उर्वर — अनुर्वर, उदात्त — अनुदात्त।
- **'दुर्' / 'दुस्' उपसर्ग द्वारा:** सजन — दुर्जन, सत्कर्म — दुष्कर्म, सुबोध — दुर्बोध, सुगम — दुर्गम।
- **'निर्' / 'निस्' उपसर्ग द्वारा:** सापेक्ष — निरपेक्ष, सजल — निर्जल, सक्रिय — निष्क्रिय, सदोष — निर्दोष।
- **'वि' उपसर्ग द्वारा:** राग — विराग, देश — विदेश, योजन — वियोजन, सम — विषम।
- **'प्रति' उपसर्ग द्वारा:** वादी — प्रतिवादी, घात — प्रतिघात, अनुकूल — प्रतिकूल, प्रत्यक्ष — परोक्ष।

## 3. तत्सम एवं तद्भव शब्द (Rules & Master Identification Matrix)

> **परिभाषा:**
> - **तत्सम (तत् + सम):** वे शब्द जो संस्कृत से बिना किसी परिवर्तन के हिंदी में ज्यों के त्यों प्रयुक्त होते हैं (उदा. *अग्नि, क्षेत्र, दुग्ध, कर्पूर*)।
> - **तद्भव (तत् + भव):** वे शब्द जो संस्कृत से उत्पन्न होकर प्राकृत, अपभ्रंश से होते हुए समय के साथ विकृत या परिवर्तित होकर हिंदी में आए हैं (उदा. *आग, खेत, दूध, कपूर*)।

### A. तत्सम-तद्भव पहचान के 7 अकाट्य स्वर्णिम नियम (Phonetic Rules)

1. **'क्ष' का परिवर्तन 'ख' या 'छ' में:** तत्सम का 'क्ष' तद्भव में प्रायः 'ख' या 'छ' बन जाता है।  
   *उदा:* क्षीर -> खीर, क्षेत्र -> खेत, अक्षि -> आँख, पक्षी -> पंछी, मक्षिका -> मक्खी, लक्ष्मण -> लखन।
2. **'श' (तालव्य) का 'स' (दंत्य) में परिवर्तन:** तत्सम का 'श' तद्भव में 'स' बन जाता है।  
   *उदा:* श्यामल -> साँवला, शुष्क -> सूखा, श्यालक -> साला, शुक -> सुआ, शून्य -> सूना, श्वशुर -> ससुर।
3. **'व' का 'ब' में परिवर्तन:** तत्सम का 'व' ध्वनि तद्भव में 'ब' में बदल जाती है।  
   *उदा:* विद्युत -> बिजली, वधु -> बहू, वरयात्रा -> बारात, वानर -> बन्दर, वत्स -> बछड़ा, वार्ता -> बात।
4. **'ऋ' (स्वर) का प्रयोग सदैव तत्सम में:** जिन शब्दों में 'ऋ' की मात्रा (कृ, मृत, घृत) या 'र' के रूप (प्र, क्र, र्क) आते हैं, वे सदैव तत्सम होते हैं। तद्भव में वे 'रि' या साधारण स्वर बन जाते हैं।  
   *उदा:* घृत -> घी, मृतिका -> मिट्टी, दृष्टि -> दीठ, भ्रातृ -> भाई, शृंगार -> सिंगार।
5. **'य' का 'ज' में परिवर्तन:** तत्सम का 'य' तद्भव में प्रायः 'ज' में परिवर्तित हो जाता है।  
   *उदा:* यजमान -> जजमान, युवा -> जवान, यमुना -> जमुना, यम -> जम, योगी -> जोगी, यश -> जस।
6. **चंद्रबिन्दु (ँ) का प्रयोग सदैव तद्भव में:** तत्सम में अनुस्वार (ं) या अनुनासिक व्यंजन होते हैं; चंद्रबिन्दु (ँ) युक्त शब्द 100% तद्भव होते हैं।  
   *उदा:* ग्राम -> गाँव, दन्त -> दाँत, चन्द्र -> चाँद, अक्षी -> आँख, मुख -> मुँह, धूम -> धुँआ।
7. **'ज्ञ' का 'ज' या 'ग्य' में परिवर्तन:** तत्सम का 'ज्ञ' तद्भव में 'ज' बन जाता है।  
   *उदा:* ज्ञान -> जान, राज्ञी -> रानी, अज्ञान -> अजान।

## 4. अनेक शब्दों के लिए एक शब्द (One-Word Substitution Master Reference)

> **Thematic Classification:** UPPSC में वाक्यांशों को अक्सर दिशाओं, इच्छाओं, अग्नि के प्रकारों और स्त्री-संबंधी विशिष्ट शब्दों पर केंद्रित करके पूछा जाता है।

### A. दिशाओं से संबंधित महत्वपूर्ण पद (Compass Points — UPPSC Direct Trap)

```
                     उत्तर (North)
                           ↑
       वायव्य              │              ईशान
    (उत्तर-पश्चिम)         │          (उत्तर-पूर्व)
           ↖               │               ↗
 पश्चिम ───────────────────┼─────────────────── पूर्व
 (West)                    │                   (East)
           ↙               │               ↘
       नैऋत्य              │              आग्नेय
    (दक्षिण-पश्चिम)        │          (दक्षिण-पूर्व)
                           ↓
                    दक्षिण (South)
```

| दिशा का नाम | वाक्यांश |
|---|---|
| **ईशान** | उत्तर और पूर्व के बीच की दिशा |
| **आग्नेय** | पूर्व और दक्षिण के बीच की दिशा |
| **नैऋत्य** | दक्षिण और पश्चिम के बीच की दिशा |
| **वायव्य** | पश्चिम और उत्तर के बीच की दिशा |

### B. अग्नि के तीन प्रमुख प्रकार
- **दावानल / दावाग्नि:** जंगल में अपने आप लगने वाली आग।
- **जठरानल / जठराग्नि:** पेट की आग (पाचन शक्ति)।
- **बड़वानल / बड़वाग्नि:** समुद्र में लगने वाली आग।

### C. नायिका एवं स्त्री भेद (High-Frequency Literature Terms)
- **असूर्यंपश्या:** वह स्त्री जो सूर्य भी न देख सके (कड़े पर्दे में रहने वाली)।
- **वाग्दत्ता:** वह कन्या जिसके विवाह का वचन दे दिया गया हो।
- **परित्यक्ता:** पति द्वारा छोड़ दी गई स्त्री।
- **प्रोषितपतिका:** वह स्त्री जिसका पति परदेस (विदेश) चला गया हो।
- **आगतपतिका:** वह स्त्री जिसका पति परदेस से लौट आया हो।
- **प्रवत्स्यत्पतिका:** वह स्त्री जिसका पति परदेस जाने वाला हो।
- **अध्यूढ़ा:** वह स्त्री जिसका पति दूसरा विवाह कर ले।
- **सधवा:** जिस स्त्री का पति जीवित हो।
- **विधवा:** जिस स्त्री का पति मर चुका हो।
- **अभिसारिका:** वह स्त्री जो अपने प्रेमी से मिलने स्वयं संकेत स्थल पर जाती हो।
- **खंडिता:** वह स्त्री जिसका पति रात में किसी अन्य स्त्री के पास रहकर प्रातः आया हो।
- **कलहांतरिता:** वह स्त्री जो कलह के कारण अपने पति से रूठ गई हो।

### F. विविध उच्च-प्राथमिकता वाक्यांश
- **अकिंचन:** जिसके पास कुछ भी न हो।
- **अप्रमेय:** जिसे प्रमाण द्वारा सिद्ध न किया जा सके (अपरिमेय = जिसे मापा न जा सके)।
- **अतीन्द्रिय / अगोचर:** जो इंद्रियों के ज्ञान से परे हो।
- **अदत्त:** जो दिया न गया हो।
- **अनुश्रुति:** जो परंपरा से सुना गया हो।
- **अंत्यज:** जिसका जन्म तथाकथित निचली जाति में हुआ हो।
- **किंकर्तव्यविमूढ़:** जिसे यह न सूझ पड़े कि अब क्या करना चाहिए।
- **कृतज्ञ:** जो किए गए उपकार को मानता हो (कृतघ्न = उपकार न मानने वाला)।
- **दत्तक:** गोद लिया गया पुत्र।
- **पाथेय:** यात्रा में उपभोग के लिए मार्ग का भोजन/सामग्री।
- **पतित:** जो अपने स्थान या मर्यादा से गिरा हुआ हो।
- **मर्मज्ञ:** जो किसी गूढ़ रहस्य या मर्म को जानने वाला हो।
- **यायावर:** एक स्थान पर टिक कर न रहने वाला / सदैव भ्रमणशील।
- **सव्यसाची:** जो बाएँ हाथ से भी बाण चला सके / बाएँ हाथ से काम करने में दक्ष (अर्जुन)।
- **समिधा:** यज्ञ या हवन में जलाने वाली पवित्र लकड़ी।
- **स्वयंभू:** जो स्वतः उत्पन्न हुआ हो।

### B. वाक्य रचना संबंधी 7 प्रमुख नियम एवं शुद्ध-अशुद्ध उदाहरण

1. **'अनेक' सदैव बहुवचन है ('अनेकों' सर्वथा अशुद्ध):**
   - ❌ *अशुद्ध:* भगवान श्री कृष्ण के अनेकों नाम हैं।
   - ✔️ *शुद्ध:* भगवान श्री कृष्ण के **अनेक** नाम हैं।
   - ❌ *अशुद्ध:* वहाँ अनेकों लोग उपस्थित थे।
   - ✔️ *शुद्ध:* वहाँ **अनेक** लोग उपस्थित थे।

2. **नित्य बहुवचन शब्द (प्राण, आँसू, हस्ताक्षर, बाल, दर्शन, लोग, होश):**
   - ❌ *अशुद्ध:* मेरा प्राण संकट में पड़ गया।
   - ✔️ *शुद्ध:* मेरे **प्राण** संकट में पड़ **गए**।
   - ❌ *अशुद्ध:* उसकी आँख से आँसू बह रहा था।
   - ✔️ *शुद्ध:* उसकी आँखों से **आँसू बह रहे थे**।
   - ❌ *अशुद्ध:* मैंने आवेदन पत्र पर हस्ताक्षर कर दिया।
   - ✔️ *शुद्ध:* मैंने आवेदन पत्र पर **हस्ताक्षर कर दिए**।

3. **पदक्रम संबंधी दोष (विशेषण को सही संज्ञा के पूर्व लगाना):**
   - ❌ *अशुद्ध:* यहाँ शुद्ध गाय का दूध मिलता है।
   - ✔️ *शुद्ध:* यहाँ गाय का **शुद्ध दूध** मिलता है।
   - ❌ *अशुद्ध:* एक फूलों की माला ले आइए।
   - ✔️ *शुद्ध:* **फूलों की एक माला** ले आइए।
   - ❌ *अशुद्ध:* शीतल गन्ने का रस पिलाइए।
   - ✔️ *शुद्ध:* गन्ने का **शीतल रस** पिलाइए।

4. **पुनरुक्ति एवं द्विरुक्ति दोष (समानार्थी शब्दों का एक साथ प्रयोग):**
   - ❌ *अशुद्ध:* कृपया करके मुझे एक दिन का अवकाश दें।
   - ✔️ *शुद्ध:* **कृपया** मुझे एक दिन का अवकाश दें। (या: कृपा करके मुझे अवकाश दें)
   - ❌ *अशुद्ध:* वह सकुशलतापूर्वक अपने घर पहुँच गया।
   - ✔️ *शुद्ध:* वह **सकुशल** अपने घर पहुँच गया। (या: कुशलतापूर्वक पहुँच गया)
   - ❌ *अशुद्ध:* विंध्याचल पर्वत अत्यंत प्राचीन है।
   - ✔️ *शुद्ध:* **विंध्याचल** अत्यंत प्राचीन है। ('अचल' का अर्थ पर्वत ही है)
   - ❌ *अशुद्ध:* प्रातःकाल के समय टहलना चाहिए।
   - ✔️ *शुद्ध:* **प्रातःकाल** टहलना चाहिए। ('काल' का अर्थ समय ही है)

5. **'प्रत्येक' एवं 'हर एक' के साथ एकवचन संज्ञा व क्रिया:**
   - ❌ *अशुद्ध:* इस कक्षा के प्रत्येक छात्रों को पुरस्कार मिला।
   - ✔️ *शुद्ध:* इस कक्षा के **प्रत्येक छात्र** को पुरस्कार मिला।
   - ❌ *अशुद्ध:* प्रत्येक वृक्ष फल देते हैं।
   - ✔️ *शुद्ध:* प्रत्येक वृक्ष फल **देता है**।

6. **उपयुक्त शब्द-चयन दोष (अनुपयुक्त संज्ञा/क्रिया):**
   - ❌ *अशुद्ध:* साहित्य और समाज का घोर संबंध है।
   - ✔️ *शुद्ध:* साहित्य और समाज का **घनिष्ठ संबंध** है।
   - ❌ *अशुद्ध:* हमारे शिक्षक बड़े विद्वान और विदुषी हैं।
   - ✔️ *शुद्ध:* हमारे शिक्षक बड़े **विद्वान** हैं। (विदुषी स्त्री के लिए प्रयुक्त होता है)
   - ❌ *अशुद्ध:* बंदूक एक उपयोगी अस्त्र है।
   - ✔️ *शुद्ध:* बंदूक एक उपयोगी **शस्त्र** है। (शस्त्र = हाथ में पकड़कर चलाने वाला; अस्त्र = फेंककर चलाने वाला जैसे बाण/भाला)

7. **सर्वनाम एवं लिंग संबंधी दोष:**
   - ❌ *अशुद्ध:* मैंने मेरे घर जाना है।
   - ✔️ *शुद्ध:* **मुझे अपने** घर जाना है।
   - ❌ *अशुद्ध:* दही खट्टी है।
   - ✔️ *शुद्ध:* **दही खट्टा है**। (दही पुल्लिंग है)
   - ❌ *अशुद्ध:* मेरी आयु 25 वर्ष है।
   - ✔️ *शुद्ध:* मेरी **अवस्था** 25 वर्ष है। (आयु संपूर्ण जीवन-काल के लिए प्रयुक्त होती है; जीवन के किसी पड़ाव के लिए 'अवस्था' या 'उम्र')

   - यदि शब्द संज्ञा के साथ सटीक बैठता है, तो वह **विशेषण** है (उदा. *धार्मिक व्यक्ति* -> 'धार्मिक' विशेषण है)।
   - यदि शब्द के साथ संज्ञा नहीं बैठती, बल्कि वह स्वयं किसी वस्तु/भाव का नाम है, तो वह **विशेष्य** है (उदा. *धर्म* व्यक्ति नहीं होता, अतः 'धर्म' विशेष्य है)।
2. **विधेय विशेषण vs विशेष्य विशेषण:**
   - **विशेष्य विशेषण:** जो विशेष्य से पहले आए (उदा. *'सुंदर' बालक खेल रहा है*)।
   - **विधेय विशेषण:** जो विशेष्य के बाद और क्रिया से पहले आए (उदा. *मेरा कुत्ता 'काला' है*)।

## 7. मुहावरे एवं लोकोक्तियाँ (Idioms & Proverbs — Meaning & Administrative Sentences)

> **UPPCS Mains Rule (30 अंक):** परीक्षा में मुहावरे का **सटीक अर्थ** लिखने के बाद ऐसा **वाक्य प्रयोग** करना होता है जिससे मुहावरे का अर्थ पूरी तरह स्पष्ट हो जाए। घिसे-पिटे या बचकाने वाक्यों के स्थान पर प्रशासनिक, सामाजिक अथवा समसामयिक संदर्भ वाले परिपक्व वाक्य लिखने पर पूरे अंक मिलते हैं।

### A. अति-महत्वपूर्ण मुहावरे: अर्थ एवं मानक प्रशासनिक वाक्य प्रयोग

1. **अंगूठा दिखाना**
   - **अर्थ:** ऐन वक्त पर साफ इनकार कर देना / सहायता न करना।
   - **वाक्य प्रयोग:** जब बाढ़ राहत कार्य में ठेकेदार ने आवश्यक नौकाएँ उपलब्ध कराने से अंगूठा दिखा दिया, तब जिलाधिकारी ने आपदा प्रबंधन बल को सीधे तैनात किया।

2. **अंगार बरसना**
   - **अर्थ:** अत्यधिक भीषण गर्मी पड़ना।
   - **वाक्य प्रयोग:** बुंदेलखंड में ज्येष्ठ माह की दोपहर में जब आसमान से अंगार बरस रहे थे, तब जल-संस्थान के कर्मी दूरस्थ गाँवों तक टैंकर पहुँचाने में जुटे थे।

3. **अक्ल का अंधा / अक्ल का दुश्मन**
   - **अर्थ:** महामूर्ख होना / बुद्धिहीन होना।
   - **वाक्य प्रयोग:** उस कनिष्ठ लिपिक को अक्ल का अंधा ही कहेंगे जिसने उच्चाधिकारियों की गोपनीय पत्रावली अनाधिकृत व्यक्ति को सौंप दी।

4. **अपना उल्लू सीधा करना**
   - **अर्थ:** केवल अपना स्वार्थ सिद्ध करना।
   - **वाक्य प्रयोग:** स्वार्थी नेता जनता के मौलिक मुद्दों की उपेक्षा कर चुनाव के समय जातिगत उन्माद फैलाकर केवल अपना उल्लू सीधा करते हैं।

5. **अपने पैरों पर कुल्हाड़ी मारना**
   - **अर्थ:** जानबूझकर स्वयं अपना अहित या नुकसान करना।
   - **वाक्य प्रयोग:** प्रतियोगी परीक्षा की मुख्य तिथि निकट होने पर भी अध्ययन छोड़कर व्यर्थ विवादों में उलझना अपने पैरों पर स्वयं कुल्हाड़ी मारने जैसा है।

6. **आँखें खुलना**
   - **अर्थ:** वास्तविकता का बोध होना / भ्रम दूर होना।
   - **वाक्य प्रयोग:** जब ऑडिट टीम ने कार्यालय के फर्जी बिलों की वित्तीय अनियमितता उजागर की, तब विभाग प्रमुख की आँखें खुलीं।

7. **आड़े हाथों लेना**
   - **अर्थ:** खरी-खोटी सुनाना / निरुत्तर करना / कठोरता से जवाबदेही तय करना।
   - **वाक्य प्रयोग:** विकास योजनाओं में भारी लापरवाही पाए जाने पर मुख्य सचिव ने समीक्षा बैठक में सभी कार्यदायी संस्थाओं को आड़े हाथों लिया।

8. **उल्टी गंगा बहाना**
   - **अर्थ:** स्थापित नियमों, परंपरा या औचित्य के विपरीत आचरण करना।
   - **वाक्य प्रयोग:** वरिष्ठ और योग्य अधिकारियों को दरकिनार कर कनिष्ठ कर्मचारियों को नीतिगत निर्णय सौंपना शासन में उल्टी गंगा बहाने के समान है।

9. **काठ का उल्लू**
   - **अर्थ:** निपट मूर्ख / सर्वथा निष्प्रभ व्यक्ति।
   - **वाक्य प्रयोग:** संकटकाल में जब त्वरित प्रशासनिक निर्णय लेने थे, तब उपजिलाधिकारी महोदय काठ के उल्लू की भाँति मूकदर्शक बने रहे।

10. **खून-पसीना एक करना**
    - **अर्थ:** अत्यधिक कठोर परिश्रम करना।
    - **वाक्य प्रयोग:** भारतीय कृषक ग्रीष्म की तपती धूप और शीत की ठिठुरन में खून-पसीना एक करके देश के लिए अन्न उपजाते हैं।

11. **गूलर का फूल होना**
    - **अर्थ:** अत्यंत दुर्लभ होना / अप्रकट या न दिखाई पड़ना।
    - **वाक्य प्रयोग:** स्थानांतरण के बाद जब से शर्मा जी बड़े संभाग के उपायुक्त बने हैं, अपने पुराने मित्रों के लिए गूलर का फूल हो गए हैं।

12. **घड़ों पानी पड़ना**
    - **अर्थ:** अत्यधिक लज्जित होना।
    - **वाक्य प्रयोग:** रिश्वत लेते रंगे हाथों विजिलेंस टीम द्वारा पकड़े जाने पर भ्रष्ट अधिकारी पर घड़ों पानी पड़ गया।

13. **चिकना घड़ा होना**
    - **अर्थ:** जिस पर किसी उपदेश या चेतावनी का कोई प्रभाव न पड़े / निर्लज्ज होना।
    - **वाक्य प्रयोग:** बार-बार चेतावनी पत्र दिए जाने पर भी वह अनुपस्थित कर्मचारी चिकना घड़ा साबित हुआ और उसने अपनी कार्यशैली नहीं बदली।

14. **छाती पर मूँग दलना**
    - **अर्थ:** निकट रहकर लगातार मानसिक कष्ट या पीड़ा पहुँचाना।
    - **वाक्य प्रयोग:** पड़ोसी राष्ट्र अपनी सीमा से सीमापार आतंकवाद प्रायोजित कर वर्षों से भारत की छाती पर मूँग दलने का कुत्सित प्रयास कर रहा है।

15. **तिल का ताड़ बनाना**
    - **अर्थ:** छोटी-सी सामान्य बात को अत्यधिक तूल देना या बढ़ा-चढ़ाकर कहना।
    - **वाक्य प्रयोग:** प्रशासनिक समन्वय की सामान्य बैठक में हुई वैचारिक असहमति का तिल का ताड़ बनाकर सनसनीखेज मीडिया ने गलत माहौल बनाया।

16. **दाँत खट्टे करना**
    - **अर्थ:** शत्रु को बुरी तरह पराजित करना / पछाड़ना।
    - **वाक्य प्रयोग:** कारगिल युद्ध में भारतीय वीर जवानों ने दुर्गम चोटियों पर बैठे घुसपैठियों के दाँत खट्टे कर तिरंगा फहराया।

17. **पसीना-पसीना होना**
    - **अर्थ:** अत्यधिक भयभीत या लज्जित होना।
    - **वाक्य प्रयोग:** जांच आयोग के तीखे और अकाट्य प्रश्नों के सामने संलिप्त ठेकेदार पसीना-पसीना हो गया।

18. **बट्टा लगाना**
    - **अर्थ:** प्रतिष्ठा धूमिल करना / कलंक लगाना।
    - **वाक्य प्रयोग:** किसी भी लोकसेवक द्वारा किया गया भ्रष्ट आचरण पूरे प्रशासनिक तंत्र की निष्ठा पर बट्टा लगा देता है।

19. **भानुमती का पिटारा**
    - **अर्थ:** अनेक प्रकार की बेमेल और विचित्र वस्तुओं या विचारों का अस्वाभाविक जमावड़ा।
    - **वाक्य प्रयोग:** बिना किसी नीतिगत सहमति के गठित यह साझा गठबंधन प्रशासनिक सुधार के नाम पर भानुमती का पिटारा सिद्ध हुआ।

20. **लकीर का फकीर होना**
    - **अर्थ:** परंपरावादी होना / नवीन विचारों को न अपनाकर पुराने ढर्रे पर चलना।
    - **वाक्य प्रयोग:** डिजिटल क्रांति के युग में भी फाइलों के पुराने ढर्रे पर चलना और लकीर का फकीर बने रहना आधुनिक सुशासन में बाधक है।

### B. अति-महत्वपूर्ण लोकोक्तियाँ: अर्थ एवं वाक्य प्रयोग

1. **अंधेर नगरी चौपट राजा, टके सेर भाजी टके सेर खाजा**
   - **अर्थ:** जहाँ शासन में घोर अव्यवस्था, अन्याय और गुण-दोष का कोई विवेक न हो।
   - **वाक्य प्रयोग:** उस निजी कंपनी में परिश्रमी अधिकारी और अकर्मण्य कर्मचारी को समान वेतन दिया जाता था, सचमुच वही हाल था— अंधेर नगरी चौपट राजा।

2. **अपनी डफली अपना राग**
   - **अर्थ:** परस्पर तालमेल का सर्वथा अभाव / सबका मनमाना मत होना।
   - **वाक्य प्रयोग:** जब अंतर-विभागीय समन्वय समिति में सभी विभागाध्यक्ष अपनी डफली अपना राग अलापने लगे, तो परियोजना का कार्य रुक गया।

3. **आम के आम गुठलियों के दाम**
   - **अर्थ:** दोहरा अथवा अत्यधिक लाभ होना।
   - **वाक्य प्रयोग:** लखनऊ प्रवास के दौरान अधिकारी ने शासकीय बैठक भी संपन्न की और हस्तशिल्प प्रदर्शनी देखकर घरेलू खरीदारी भी की, इसे कहते हैं आम के आम गुठलियों के दाम।

4. **आसमान से गिरा खजूर में अटका**
   - **अर्थ:** एक विपत्ति से छूटकर दूसरी नई विपत्ति में फँसना।
   - **वाक्य प्रयोग:** उस निर्धन किसान ने साहूकार का ऋण चुकाने के लिए जमीन बेची ही थी कि सूखा पड़ गया; उसका तो वही हाल हुआ— आसमान से गिरा खजूर में अटका।

5. **कंगाली में आटा गीला**
   - **अर्थ:** पहले से विद्यमान संकट में और नया संकट आ पड़ना।
   - **वाक्य प्रयोग:** व्यापार में मंदी के कारण पहले ही नुकसान हो रहा था, ऊपर से गोदाम में आग लग जाने से कंगाली में आटा गीला हो गया।

6. **जाके पाँव न फटे बिवाई, वो क्या जाने पीर पराई**
   - **अर्थ:** जिस पर स्वयं कष्ट नहीं बीतता, वह दूसरों की वास्तविक पीड़ा को नहीं समझ सकता।
   - **वाक्य प्रयोग:** वातानुकूलित कमरों में बैठकर नीतियाँ बनाने वाले नीति-निर्माता जब तक ग्रामीण धरातल पर नहीं जाएँगे, वे क्या समझेंगे— जाके पाँव न फटे बिवाई, वो क्या जाने पीर पराई।

7. **धोबी का कुत्ता न घर का न घाट का**
   - **अर्थ:** जिसका कहीं कोई स्थायी ठिकाना या सम्मान न रहे।
   - **वाक्य प्रयोग:** दलबदल के चक्कर में विधायक जी ने अपनी मूल पार्टी भी छोड़ दी और नई पार्टी ने भी उन्हें टिकट नहीं दिया, अब उनकी स्थिति धोबी के कुत्ते जैसी हो गई।

8. **नाच न जाने आँगन टेढ़ा**
   - **अर्थ:** अपनी अयोग्यता और दोष को छिपाने के लिए साधनों में कमी निकालना।
   - **वाक्य प्रयोग:** जब सॉफ्टवेयर इंजीनियर निर्धारित लक्ष्य पूरा न कर सका, तो उसने कंप्यूटर सिस्टम को ही धीमा बता दिया; इसे कहते हैं नाच न जाने आँगन टेढ़ा।

9. **हाथ कंगन को आरसी क्या**
   - **अर्थ:** प्रत्यक्ष प्रमाण के सामने किसी अन्य साक्ष्य की आवश्यकता नहीं होती।
   - **वाक्य प्रयोग:** जिले में अपराध दर में आई भारी गिरावट पुलिस अधीक्षक के उत्कृष्ट कार्य का प्रत्यक्ष प्रमाण है, हाथ कंगन को आरसी क्या।

- **उर्दू / फ़ारसी उपसर्ग:**
  - **कम** (थोड़ा): कमजोर, कमअक्ल, कमउम्र।
  - **खुश** (अच्छा): खुशखबरी, खुशबू, खुशमिजाज, खुशनसीब।

### C. प्रत्यय (Suffixes) के दो प्रमुख भेद एवं निर्माण
1. **कृत् प्रत्यय (Krut Suffixes):**
   - जो प्रत्यय क्रिया की मूल धातु के अंत में जुड़कर संज्ञा या विशेषण शब्द बनाते हैं। इनसे बने शब्द **कृदंत** कहलाते हैं।
   - *अक:* लेख् + अक -> **लेखक**, पाठ् + अक -> **पाठक**।
   - *अन:* गम् + अन -> **गमन**, मोह् + अन -> **मोहन**।
   - *आना:* भूल + आना -> **भुलाना**, देख + आना -> **दिखाना**।
   - *आई:* पढ़ + आई -> **पढ़ाई**, लिख + आई -> **लिखाई**।
   - *आवट:* लिख + आवट -> **लिखावट**, मिल + आवट -> **मिलावट**।
   - *आहट:* घबराना + आहट -> **घबराहट**, चिल्लाना + आहट -> **चिल्लाहट**।
   - *ईय:* पूज् + ईय -> **पूजनीय / पूज्य**, स्मृ + ईय -> **स्मरणीय**।
   - *ता:* जाग् + ता -> **जागता**, बह् + ता -> **बहता**।
2. **तद्धित प्रत्यय (Taddhit Suffixes):**
   - जो प्रत्यय संज्ञा, सर्वनाम या विशेषण के अंत में जुड़कर नए शब्द बनाते हैं। इनसे बने शब्द **तद्धितांत** कहलाते हैं।
   - *आर:* सोना + आर -> **सुनार**, लोहा + आर -> **लुहार**।
   - *इक (आदि स्वर की वृद्धि):* धर्म + इक -> **धार्मिक**, इतिहास + इक -> **ऐतिहासिक**, समाज + इक -> **सामाजिक**, नीति + इक -> **नैतिक**, भूगोल + इक -> **भौगोलिक**।
   - *इमा:* लघु + इमा -> **लघिमा**, गुरु + इमा -> **गरिमा**, महा + इमा -> **महिमा**।
   - *ईला:* चमक + ईला -> **चमकीला**, रस + ईला -> **रसीला**।
   - *तम:* उच्च + तम -> **उच्चतम**, श्रेष्ठ + तम -> **श्रेष्ठतम**।
   - *वान / वती:* धन + वान -> **धनवान**, दया + वान -> **दयावान**।

## 11. गद्यांश अवबोध, शीर्षक चयन एवं संक्षेपण (Comprehension & Précis Rules)

> **UPPCS Mains Standard (60 अंक):**
> - **प्रश्नोत्तर (Comprehension):** 3 प्रश्न = 30 अंक (गद्यांश का मूल आशय, विशिष्ट प्रश्नों के उत्तर, रेखांकित पंक्तियों की व्याख्या)।
> - **संक्षेपण (Précis Writing):** 1 प्रश्न = 30 अंक (उचित शीर्षक चयन + 1/3 शब्दों में संक्षेपण)।

### A. संक्षेपण (Précis Writing) के 6 अकाट्य स्वर्णिम नियम
1. **एक-तिहाई (1/3) शब्द-सीमा:** संक्षेपण मूल गद्यांश के लगभग 30% से 35% शब्दों में होना चाहिए। यदि मूल गद्यांश 150 शब्दों का है, तो संक्षेपण 45–55 शब्दों में ही होना चाहिए।
2. **मूल भाव की अखंडता:** गद्यांश का कोई भी केंद्रीय विचार छूटना नहीं चाहिए, लेकिन उदाहरण, दृष्टांत, मुहावरे, अलंकार, उद्धरण और व्याख्यात्मक विस्तार को पूरी तरह हटा दिया जाता है।
3. **अपनी भाषा और शैली:** मूल गद्यांश के वाक्यों को ज्यों का त्यों काटना-छांटना (Cut-Copy-Paste) अक्षम्य दोष है। भाव मूल लेखक का हो, लेकिन भाषा और वाक्य विन्यास परीक्षार्थी का अपना होना चाहिए।
4. **पुरुष का प्रयोग (अन्य पुरुष):** संक्षेपण सदैव **अन्य पुरुष (Third Person)** में लिखा जाता है। मूल गद्यांश में यदि 'मैं' या 'हम' आया हो, तब भी संक्षेपण में "लेखक के अनुसार..." या सीधे तथ्यपरक शैली में लिखा जाता है।
5. **स्वयं की टीका-टिप्पणी का पूर्ण निषेध:** परीक्षार्थी को अपनी ओर से कोई नया विचार, तर्क, आलोचना या व्यक्तिगत मत जोड़ने की अनुमति नहीं होती।
6. **सुगठित एकल अनुच्छेद:** संक्षेपण सदैव एक ही सुसंबद्ध, धाराप्रवाह और व्याकरणसम्मत पैराग्राफ में लिखा जाना चाहिए।

### B. उपयुक्त शीर्षक (Title) निर्धारण तकनीक
- **शीर्षक का लक्षण:** संक्षिप्त (2 से 4 शब्द), आकर्षक, अर्थगर्भित और संपूर्ण गद्यांश के केंद्रीय विचार को समेटने वाला होना चाहिए।
- **खोजने का तरीका:** गद्यांश के प्रथम दो वाक्यों तथा अंतिम दो वाक्यों को ध्यानपूर्वक पढ़ें; 80% मामलों में लेखक केंद्रीय विषय की प्रस्तावना आरंभ में या निष्कर्ष अंत में देता है।
- **एक से अधिक विकल्प:** यदि शीर्षक के दो सटीक रूप मन में आएँ, तो एक मुख्य शीर्षक और कोष्ठक में या नीचे 'वैकल्पिक शीर्षक' लिखा जा सकता है (उदा. *मानसिक स्वास्थ्य: आधुनिक जीवन की चुनौती (वैकल्पिक: तनाव-मुक्ति का मार्ग)*)।

### C. रेखांकित अंशों की व्याख्या (Explanation of Underlined Lines)
- कभी भी रेखांकित पंक्ति का शब्द-प्रति-शब्द अनुवाद न करें।
- लेखक उस पंक्ति के माध्यम से जो गूढ़, दार्शनिक या सामाजिक संदेश देना चाहता है, उसे 3 से 5 वाक्यों में सरल, स्पष्ट एवं प्रभावोत्पादक भाषा में विस्तार दें।

## 12. संधि एवं समास त्वरित स्मरण तालिका (Sandhi & Samas High-Frequency Active Recall)

### A. प्रमुख संधि भेद एवं उच्च-प्राथमिकता परीक्षा उदाहरण

| संधि का नाम | प्रमुख नियम / सूत्र | उच्च-प्राथमिकता परीक्षा उदाहरण (Direct Hits) |
|---|---|---|
| **दीर्घ स्वर संधि** | अ/आ + अ/आ -> आ; इ/ई + इ/ई -> ई; उ/ऊ + उ/ऊ -> ऊ | परम + अर्थ = **परमार्थ**; कवि + इंद्र = **कवींद्र**; भानु + उदय = **भानूदय**; विद्या + आलय = **विद्यालय** |
| **गुण स्वर संधि** | अ/आ + इ/ई -> ए; अ/आ + उ/ऊ -> ओ; अ/आ + ऋ -> अर् | नर + इंद्र = **नरेंद्र**; महा + ईश = **महेश**; सूर्य + उदय = **सूर्योदय**; देव + ऋषि = **देवर्षि**; महा + ऋषि = **महर्षि** |
| **वृद्धि स्वर संधि** | अ/आ + ए/ऐ -> ऐ; अ/आ + ओ/औ -> औ | एक + एक = **एकैक**; मत + ऐक्य = **मतैक्य**; महा + औषधि = **महौषधि**; परम + औदार्य = **परमौदार्य** |
| **यण स्वर संधि** | इ/ई + भिन्न स्वर -> य्; उ/ऊ + भिन्न स्वर -> व्; ऋ + भिन्न स्वर -> र् | यदि + अपि = **यद्यपि**; इति + आदि = **इत्यादि**; सु + आगत = **स्वागत**; अनु + अय = **अन्वय**; पितृ + आज्ञा = **पित्राज्ञा** |
| **अयादि स्वर संधि** | ए/ऐ/ओ/औ + भिन्न स्वर -> अय् / आय् / अव् / आव् | ने + अन = **नयन**; गै + अक = **गायक**; पो + अन = **पवन**; पौ + अक = **पावक**; नौ + इक = **नाविक** |
| **व्यंजन संधि** | वर्ग के प्रथम वर्ण का तीसरे वर्ण में परिवर्तन | दिक् + गज = **दिग्गज**; वाक् + ईश = **वागीश**; अच् + अंत = **अजंत**; सत् + धर्म = **सद्धर्म**; उत् + घाटन = **उद्घाटन** |
| **व्यंजन संधि** | वर्ग के प्रथम वर्ण का पाँचवें वर्ण (अनुनासिक) में परिवर्तन | वाक् + मय = **वांग्मय**; उत् + नति = **उन्नति**; जगत् + नाथ = **जगन्नाथ**; सत् + मार्ग = **सन्मार्ग** |
| **व्यंजन संधि (त्/द् संबंधी)** | त् + च/छ -> च्च; त् + ज/झ -> ज्ज; त् + ल -> ल्ल | उत् + चारण = **उच्चारण**; सत् + जन = **सज्जन**; उत् + ज्वल = **उज्ज्वल**; उत् + लेख = **उल्लेख** |
| **विसर्ग संधि (ओ-भाव)** | विसर्ग से पूर्व 'अ' और बाद में घोष वर्ण -> 'ओ' | मनः + अनुकूल = **मनोनुकूल**; अधः + गति = **अधोगति**; तपः + वन = **तपोवन**; पयः + धर = **पयोधर**; वयः + वृद्ध = **वयोवृद्ध** |
| **विसर्ग संधि (र्-भाव)** | विसर्ग से पूर्व अ/आ से भिन्न स्वर और बाद में घोष वर्ण -> 'र्' | निः + धन = **निर्धन**; दुः + बल = **दुर्बल**; निः + उपाय = **निरुपाय**; दुः + गंध = **दुर्गंध** |
| **विसर्ग संधि (श्/ष्/स् भाव)** | विसर्ग के बाद च/छ -> श्; ट/ठ -> ष्; त/थ -> स् | निः + चिंत = **निश्चिंत**; धनुः + टंकार = **धनुष्टंकार**; नमः + ते = **नमस्ते**; निः + संकोच = **निस्संकोच** |
