## 3. Recurring themes

The paper clusters around **institutions + federal tension + rights + offices**. It is not random Article hunting.

| Theme | Typical lock |
|-------|----------------|
| Money Bill | Art. **110**, Speaker’s certificate, RS **14 days**, no joint sitting |
| Local bodies | Part **IX** vs **IXA**, women **≥1/3**, first municipal corporation **Madras 1688** |
| Federalism | Union / State / Concurrent lists, GST Council, Inter-State Council = Sarkaria 1990 |
| Offices | CAG asked often; ECI composition after the 2023 Act; UPSC vs SPSC |
| Preamble / 42nd | Socialist and Secular added by **42nd (1976)**, not by the original text |
| Basic structure | Kesavananda **1973**; 24th Amendment sits before that judgment |

---

## 4. Format shift

Older papers used more single-fact MCQs. **2023–2025** lean on:

1. Match List-I / List-II (Article, Part, body, Schedule).
2. Two or three statements — evaluate each line, then pick the code.
3. Assertion–Reason on FRs, federal features, and local government.
4. “Which is **not** correctly matched?”

Practice Zones in the topic files already mix these. Do not drill only one-liners.

## 5. Master trap checklist

| Trap | Correct lock |
|------|----------------|
| Money Bill can go to a joint sitting | Joint sitting is **not** for Money Bills or amendment Bills |
| Panchayat voter / member age is 25 | **21** years |
| SEC is a wing of the ECI | State Election Commission is **separate** |
| NITI Aayog is a constitutional body | **Executive / extra-constitutional** |
| Inter-State Council is Punchhi (2010) | Constituted after **Sarkaria**, **1990** (Art. 263) |
| CVC has a constitutional article | CVC is **statutory** |
| 42nd added only Fundamental Duties | Also **Socialist** and **Secular** in the Preamble |
| GST is the 100th Amendment | **101st** |
| Anglo-Indian LS nomination still exists | Ended by the **104th** Amendment |
