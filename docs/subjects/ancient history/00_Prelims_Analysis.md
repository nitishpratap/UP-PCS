## 3. Recurring themes

| Theme | Typical lock |
|-------|----------------|
| IVC extent | West **Sutkagen-dor**, east **Alamgirpur (UP)**, north **Manda**, south **Daimabad** |
| UP Harappan | Alamgirpur (Meerut), Hulas (Baghpat), Mandi (Bijnor) |
| Famous pairs | Great Bath = Mohenjo-daro. Dockyard = Lothal. Ploughed field = Kalibangan |
| Buddhism | Councils, Sarnath capital, UP Buddhist sites |
| Administration | Mantriparishad, bhukti / vishaya, mahadandanayaka-type terms |

Culture questions on stupas, literature, and philosophy often sit in **Art and Culture** notes. Revise both clusters together.

---

## 4. Format shift

Match List (site ↔ region, officer ↔ function) dominates. Assertion–Reason appears on IVC urban character and religious statements. Chronology is used for dynasties more than for Stone Age dates.

---

## 5. Master trap checklist

| Trap | Correct lock |
|------|----------------|
| Rakhigarhi is in UP | **Hisar, Haryana** |
| Lothal is only a warehouse town | **Dockyard** is the exam identity |
| Harappan script is fully deciphered | It is **unread** |
| Iron and coins are mature Harappan features | **No iron, no coins** in mature IVC |
| Sarnath lion capital is Mauryan art sitting only in Art notes | It is a **Mauryan + UP** lock here too |
| All chalcolithic sites are Harappan | Copper Hoard / OCP are separate UP-adjacent cultures |
