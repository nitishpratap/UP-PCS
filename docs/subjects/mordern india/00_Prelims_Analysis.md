---

## 4. Format shift

Chronology codes and Match List are the house style. Assertion–Reason is used for economic and reform statements. Post-2019 papers still love **one person, one wrong year** as statement 2.

---

## 5. Master trap checklist

| Trap | Correct lock |
|------|----------------|
| All 19th-century peasant movements are 1857 | Learn **Indigo, Pabna, Deccan, Eka** as separate files in Topic 8 |
| Cabinet Mission proposed Partition as the first plan | It proposed a **three-tier / grouping** scheme |
| Cripps offered immediate full independence | It offered **dominion status after the war** |
| Permanent Settlement is Ryotwari | Cornwallis / zamindari is **Permanent**. Ryotwari is Munro–Read |
| Revolutionary activity is only Bengal | UP, Punjab, and Maharashtra are equally testable (Topic 11) |
| Post-1947 is “Mains only” | UPPCS Prelims **does** ask integration and early institutions (Topic 15) |
