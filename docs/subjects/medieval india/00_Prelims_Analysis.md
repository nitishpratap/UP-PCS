## 4. Format shift

Match List dominates (book ↔ author, saint ↔ place, building ↔ ruler). Assertion–Reason appears on administrative claims. Chronology is used for dynasties and Mughal succession.

---

## 5. Master trap checklist

| Trap | Correct lock |
|------|----------------|
| All land-revenue experiments are Akbar’s | Sher Shah’s zabt / rupiya sit **before** Akbar |
| Tuzuk-i-Baburi is a Persian original by Babur | Babur wrote in **Chagatai Turkish** |
| Sufi silsila matching can be guessed | Learn Chishti vs Suhrawardi vs Naqshbandi traps in Topic 4 |
| Vijayanagara is only a South-Indian optional | It is a **regular** UPPCS regional-kingdom match |
| Marathas are only a Modern topic | Shivaji administration is **Medieval Topic 11** |
