## 4. Format shift

Match List is the default. “NOT correctly matched” is common for temple–dynasty and book–author. Dance and music, when asked, are almost always matching tables — which is why Topics 6–7 still matter even at zero past hits.

## 5. Master trap checklist

| Trap | Correct lock |
|------|----------------|
| All north-Indian temples are Nagara in every detail | Learn **exceptions and hybrid** rows in Topic 3 |
| Sarnath is in Madhya Pradesh | **UP** (Varanasi district) |
| Six schools of Indian philosophy can be bluffed | One founder / one text per school in Topic 2 |
| GI tags are Current Affairs only | Topic 16 holds the exam set |
| Dance has never been asked so skip Bharatanatyam–state rows | **Do not skip.** Standard coaching map. Zero past hits ≠ out of syllabus |
