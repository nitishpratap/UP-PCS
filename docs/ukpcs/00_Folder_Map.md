## What stays shared (do not duplicate)

- Indian / World History national blocks → existing Ancient, Medieval, Modern chapters  
- Indian / World Geography → existing Geography Topics 1–23 (+ UP Topic 24 stays UP-only)  
- National Polity / Constitution → existing Polity Topics 1–24 (+ UP Special Topic 25 stays UP-only)  
- Environment national → existing Environment topics  

## Naming

- Disk folder: always **`uttarakhand`** (lowercase), not `ukpcs`  
- Exam hub / syllabus desk: top-level **`ukpcs/`**  
- Chapter files inside UK folders: `NN_Short_Title.md` (same numbering style as national topics)

## After you paste PYQs

1. Tag stems as **UKPCS** (year + Q if known).  
2. Put Inline / Practice / Complete Bank entries in the matching teaching chapter or UK folder chapter.  
3. Build `prelims-analysis` UKPCS heat maps once enough years are tagged (parallel to UPPCS 2018–2025).
