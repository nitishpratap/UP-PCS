# Mains PYQ Library

Answer-writing material organised by UPPCS Mains syllabus topics. Each file targets **one keyword cluster**: past questions, quick revision, traps, and a usable answer frame.

## How to practise

1. Pick **one** subtopic file — not a whole GS paper.
2. Read only: **PYQs → Quick Revision → Traps** (3–7 minutes).
3. Write the answer in the prescribed word limit **without** looking back.
4. Compare structure: intro → 3–4 arguments with examples → conclusion / way forward.
5. Note recurring directives (`comment`, `examine`, `discuss`, `critically analyse`).

!!! tip "One theme, many years"
    If two PYQs share a file, practise both word limits. Same ammunition bank; different demand of the directive.
