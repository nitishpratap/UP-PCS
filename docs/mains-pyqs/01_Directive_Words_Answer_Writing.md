# Directive Words — How to Write the Answer the Examiner Wants

> Mains · Answer writing · Explain · Examine · Discuss · Critically examine · Evaluate · Comment

The **verb** in the question is not decoration. It is the marking scheme. Same facts under a wrong directive often score like a prepared note dumped on the page. Same facts under the right directive look like a topper copy.

This page teaches you how to **read the verb**, choose the **answer shape**, and write in the **UPPCS topper format** used in this Mains library.

**Jump to practice:** [Model answers](#model-answers-learn-the-shape-not-the-paragraph) — Explain · Discuss · Examine · Analyse · Critically examine · Evaluate · Comment · To what extent · Compound · Same theme three ways.

---

## What is a directive word?

A directive word is the **instruction** that tells you *how* to use your knowledge — not only *what* topic to cover.

Every Mains question has two parts:

| Part | Example | Job |
|------|---------|-----|
| **Content / theme** | Panchayati Raj, GST Council, Abraham Accords | What you must know |
| **Directive / verb** | Discuss, Examine, Critically evaluate | What operation the examiner wants |

If the question says **critically examine** and you only **describe**, content quality does not save you. Examiners routinely cap such answers around the middle band.

---

## The 15-second decode before you write

Do this on every question — in Hindi or English papers.

1. **Underline every verb** — discuss / examine / suggest / critically evaluate.
2. **Mark the scope limiter** — “in India”, “since 1991”, “in light of India’s stand”, “with reference to appointments”.
3. **Write one rough line** — “This question wants me to ___ (and ___).”
4. **Choose the body heading** from the table below.
5. **Match the conclusion** to the verb — map, measure, or verdict.

```
Question = Theme + Directive + Scope
Answer   = Intro + Body shaped by Directive + Close shaped by Directive
```

## UPPCS house format (use this every time)

Your answers in this library follow one fixed skeleton. Only the **middle heading and body logic** change with the directive.

```markdown
**Introduction:** (1–2 lines — define + scope)

**Main Characteristics / Main Points / Logical Analysis:** (match directive)
- **Exam Keyword Label** — Crisp line + proof/example

**Keywords (underline in exam):** A · B · C · D

**Exam diagram (30 sec):**
[hand-drawable ASCII]

**Conclusion:** (1 line — matches directive)
```

| Marks | Words | Labelled points |
|-------|-------|-----------------|
| **8M** | ~125W | 6–8 |
| **12M** | ~150–200W | 7–9 |
| **15M+** | ~250W+ | 9–12 |

## Master map — directive → demand → structure → close

| Directive | Examiner wants | Verdict? | Safe body | Safe close |
|-----------|----------------|----------|-----------|------------|
| **Define / What is** | Precise meaning + brief clarity | No | Definition → features / ambiguities | One crisp wrap |
| **Describe / Give an account** | Factual picture of features | No | Characteristics / process | Neutral summary |
| **Enumerate / List / Outline** | Point-wise inventory | No | Numbered / labelled list | Short wrap |
| **Explain / Clarify** | What–Why–How with logic | No | Mechanism + reasons + examples | Teaching close |
| **Elaborate / Elucidate** | Deeper layered explanation | No | Layers / dimensions / illustrations | Relevance line |
| **Illustrate / Substantiate** | Proof with examples or data | No | Claim → 2–3 proofs | Claim holds |
| **Trace** | Chronological sequence | No | Stage 1 → 2 → 3 | Overall arc |
| **Compare / Contrast / Differentiate** | Similarities and/or differences | No | Table or parallel bullets | Key distinction |
| **Discuss** | Multi-dimensional map / both sides | Mild / balanced | 3–4 dimensions or for–against | Balanced close |
| **Examine** | Test facts / claim; cause–effect | Mild, measured | Components → evidence → limits | How far it holds |
| **Analyse** | Break into parts + linkages | No (synthesis OK) | Parts → interlinks → insight | Systemic wrap |
| **Comment** | Informed opinion, briefly justified | Yes | 2 supports → 1 caveat → stand | Your view |
| **Evaluate / Assess** | Weigh against a standard | Yes | Criteria → performance → judgement | Explicit verdict |
| **Critically examine / analyse / evaluate** | Merits + limits + **stand** | **Yes, compulsory** | Strengths → weaknesses → verdict → way forward | Clear judgement |
| **To what extent / How far** | Degree of truth, not yes/no | Nuanced | Evidence for → limits → qualifier | Largely / partially / limited |
| **Do you agree?** | Clear stand + reasons | Yes | Stand → reasons → counter briefly | Reaffirm stand |
| **Suggest / Recommend / Way forward** | Actionable reforms | No debate dump | Named, doable measures | Priority reform |

## Hindi paper — same verbs, same shapes

UPPCS often prints the Hindi directive. Treat it as the English verb.

| Hindi cue | English directive |
|-----------|-------------------|
| व्याख्या कीजिए / स्पष्ट कीजिए | Explain |
| विवेचना कीजिए / चर्चा कीजिए / विवेचन कीजिए | Discuss |
| परीक्षण कीजिए | Examine |
| विश्लेषण कीजिए | Analyse |
| आलोचनात्मक परीक्षण कीजिए | Critically examine |
| आलोचनात्मक मूल्यांकन कीजिए | Critically evaluate |
| टिप्पणी कीजिए | Comment |
| वर्णन कीजिए | Describe |

## Directive families (learn the family, not only the word)

### 1. Descriptive family — paint the picture

**Define · Describe · Enumerate · Outline · Give an account · Trace**

- Tone is factual and orderly.
- Do **not** force a debate or a harsh verdict.
- Body heading: **Main Characteristics** / **Main Features** / chronological stages for **Trace**.

**Wrong move:** Turning a Describe question into a Critically examine essay.

### 2. Clarificatory family — teach the mechanism

**Explain · Elaborate · Elucidate · Clarify · Illustrate · Substantiate**

- Answer the **What**, then **Why/How**, then **proof**.
- **Illustrate / Substantiate** need concrete cases, data, Articles, schemes, or judgments.
- Body heading: **Main Points** (mechanism labels) or **Illustrations** after a short explanation.

**Explain** = make the logic clear.  
**Elucidate** = make a dense idea clearer with layers.  
**Illustrate** = show it with examples.

### 3. Comparative family — set items side by side

**Compare · Contrast · Differentiate · Distinguish**

- Prefer a small table or parallel labelled bullets.
- **Differentiate** = differences only. **Compare** = similarities (and often differences).

### 4. Critical / argumentative family — map, test, or judge

**Discuss · Examine · Analyse · Comment · Evaluate · Critically … · To what extent · Do you agree?**

This family decides ranks. The next section separates the close cousins.

## Confused pairs (highest-yield)

| Pair | Axis | What to do |
|------|------|------------|
| **Examine vs Analyse** | Claim vs system | **Examine** tests a claim or working against evidence (“how far / why”). **Analyse** opens the system into parts and shows how parts interact. |
| **Discuss vs Critically examine** | Map vs verdict | **Discuss** maps dimensions / both sides; fence-sitting is OK if balanced. **Critically examine** needs an **explicit stand**. |
| **Explain vs Discuss** | Teach vs debate | **Explain** clarifies mechanism. **Discuss** invites multi-dimensional argument. |
| **Evaluate vs Critically analyse** | Both need judgement | **Evaluate** weighs against a criterion (success, impact, worth). **Critically analyse** breaks into parts **and** judges. |
| **Comment vs Discuss** | Opinion-first vs map-first | **Comment** = short reasoned view. **Discuss** = fuller map of the issue. |
| **Critically ≠ only negative** | Judgement ≠ attack | “Critically” means **weigh and judge**. You may conclude something is largely sound — if limits are honestly shown. |

### One-line locks

- **Discuss** → map the issue.
- **Examine** → test the claim / working.
- **Analyse** → open the machine.
- **Critically …** → open / weigh **then** deliver a verdict.
- **Evaluate** → score it against a yardstick.
- **Comment** → say what you think, briefly and with proof.

## Same theme, three different answers

Theme: **Local self-government / 73rd–74th Amendments**

### A. Discuss the working of local self-government in India.

**Body job:** Map dimensions — design, devolution of 3Fs, capacity, participation, achievements, gaps.  
**Close:** Balanced — representation improved; resources and autonomy incomplete.  
**Do not** pick a hard yes/no fight.

### B. Examine whether the 73rd and 74th Amendments have made panchayats effective units of self-government.

**Body job:** Test the claim. Evidence for (reservations, SFCs, gram sabha) and against (parallel bodies, tied funds, weak own revenue).  
**Close:** Measured — “effective in representation, incomplete in functional autonomy.”

### C. Local bodies have not proved effective instruments of governance. Critically analyse.

**Body job:** Dissect the statement → merits of the critique → counter-evidence → **your verdict** → way forward.  
**Close:** Explicit judgement + one reform line. Fence-sitting is penalised here.

Same syllabus reading. Three different papers.

## How to write each major directive (exam-ready)

### Explain

**Demand:** Clarify What–Why–How. Teaching tone.

**Body heading:** Main Points  
**Shape:** Definition → mechanism / reasons → 1–2 examples → limit if needed  
**Conclusion:** Restate the clarified logic in one line.

**UPPCS flavour:** “Abraham Accords are a new beginning… Explain.” → normalisation logic, drivers, India’s gain, residual limits — not a full IR debate.

### Examine

**Demand:** Scrutinise; establish facts; cause–effect; mild test of “how far”.

**Body heading:** Main Points  
**Shape:** Claim / working → components → evidence → friction points / limits  
**Conclusion:** Measured finding (“holds partially…”, “works on X, weak on Y”).

**UPPCS flavour:** “Examine major issues of dispute… and give suggestions.” → first half examine, second half suggest (compound).

### Discuss

**Demand:** Multi-dimensional view; often both sides; stakeholders.

**Body heading:** Main Points  
**Shape:** 3–4 dimensions **or** For → Against → synthesis  
**Conclusion:** Balanced close — not a war cry, not a shrug.

**UPPCS flavour:** Most common GS verb (विवेचना). Do not turn every Discuss into Critically examine.

### Analyse

**Demand:** Break into parts; show linkages and causality.

**Body heading:** Logical Analysis (+ Illustrations if space)  
**Shape:** Part A → Part B → how they interact → overall insight  
**Conclusion:** Systemic synthesis (“X works only when A, B and C move together”).

### Evaluate / Assess

**Demand:** Weigh performance against a purpose or standard.

**Body heading:** Main Points (split Successes / Shortfalls) or Merits / Demerits  
**Shape:** Criteria → evidence of success → evidence of failure → judgement  
**Conclusion:** Clear verdict (“largely successful but…”, “mixed outcomes…”).

### Critically examine / Critically analyse / Critically evaluate

**Demand:** Fair weighing **plus** an explicit stand. Both strengths and weaknesses must appear.

**Body heading:** Main Points (use sub-labels: Strengths / Limitations / Verdict)  
**Shape:** Merits → demerits → **your judgement** → way forward  
**Forced pivot line (write once):** “However, three structural limits remain…”

**UPPCS flavour:** “Critically examine the jurisdiction of ICJ.” → powers + consent limits + enforcement politics + clear closing judgement.

**Trap:** Being only negative, or only praising. Critical ≠ cynical.

### Comment

**Demand:** Short analytical opinion with justification.

**Body heading:** Main Points  
**Shape:** 2 supporting reasons → 1 caveat → opinion line  
**Conclusion:** Your view in one sentence.

### To what extent / How far

**Demand:** Degree answer — largely / partially / to a limited extent.

**Body heading:** Main Points  
**Shape:** Evidence supporting the claim → evidence limiting it → qualifier  
**Conclusion:** “To a large / partial / limited extent…” — never pure yes/no without degree.

### Suggest / Recommend (often the second half)

**Demand:** Actionable, named, realistic measures.

**Shape:** 4–6 reform bullets — institution / scheme / law / capacity / finance  
**Trap:** Vague lines like “more awareness is needed”. Prefer “strengthen State Finance Commissions”, “time-bound MoP”, “Inter-State Council”, etc.

## Compound questions (two verbs = two body blocks)

Count the verbs before you write.

| Pattern | Body split | Example |
|---------|------------|---------|
| Examine **and** suggest | ~60% examine + ~40% suggest | India–Bangladesh disputes + suggestions |
| Discuss **and** comment | ~60% discuss + ~40% opinion | Discuss impact; comment on implications |
| What is X? **Suggest** reforms | ~50% + ~50% | Definition/features then reforms |
| Critically examine **in light of** Y | Y is the **lens**, not a second essay | Critically evaluate UNSC **in light of India’s stand** |

Never merge two verbs into one undifferentiated paragraph block.

---

## Introduction and conclusion must obey the verb

| Directive family | Intro style | Conclusion style |
|------------------|-------------|------------------|
| Define / Describe / Explain | Definitional + scope | Neutral / teaching wrap |
| Discuss | Issue framing | Balanced synthesis |
| Examine | Claim or institution framed | Measured “how far” line |
| Analyse | System framed as parts | Linkage synthesis |
| Comment / Agree | Position can be signalled early | Reaffirm stand |
| Evaluate / Critically … | Criteria or contested claim | **Explicit verdict** + optional way forward |

**Banned stock close for critical questions:** “Thus a holistic approach is the need of the hour.”  
**Better:** One judgement + one named reform instrument.

---

## Presentation that earns easy marks

- **Labelled bullets** beat long unmarked paragraphs in UPPCS GS.
- Every bullet starts with an **exam keyword label**, then one proof line.
- Keep a **Keywords underline list** (4–7 terms) for the examiner’s eye.
- Draw one **30-second ASCII diagram** — tree, fork, or flow — not art.
- Use **PEEL** inside each point when stuck: Point → Explain → Example → Link back to the verb.
- For 8-markers, depth; for 15-markers, add one extra dimension or a way-forward block if the verb allows.

## Model answers — learn the shape, not the paragraph

These are **original house-format models** built from real UPPCS / standard Mains stems. Read each for **directive fidelity**: intro type, body shape, and closing line. Word counts target UPPCS **8M ≈ 125W** and **12M ≈ 200W**.

After reading a model, cover it and rewrite the **skeleton only** (headings + 6 labels + close) in 4 minutes.

---

### Model 1 — Explain (mechanism / why it is true)

**Q.** “The President of India cannot become a dictator.” **Explain.** *(UPPCS 2020 pattern · 8M · 125W)*

**Why this shape:** Prove the statement with constitutional checks — not a debate on presidential vs parliamentary systems.

**Introduction:**
> The Indian President is a constitutional head under a parliamentary system. Multiple checks make personal dictatorship structurally difficult.

**Main Points:**
- **Parliamentary Executive** — Real executive power lies with the Council of Ministers (Arts 74–75).
- **Aid and Advice** — The President acts on Cabinet advice; 42nd and 44th Amendments tightened this.
- **Collective Responsibility** — The Council is responsible to the Lok Sabha, not to the President alone.
- **Impeachment** — Art 61 allows removal for violation of the Constitution.
- **Fixed Process Limits** — Ordinances, emergencies and pardons operate inside constitutional conditions.
- **Judicial Review** — Unconstitutional acts can be struck down by courts.
- **Election Check** — An electoral college and fixed tenure reduce personal capture of the office.

**Keywords (underline in exam):** Art 74 · Art 75 · Art 61 · Parliamentary System · Aid and Advice · Judicial Review

**Exam diagram (30 sec):**
```
President
 |-- acts on Cabinet advice (74-75)
 |-- removable (61)
 |-- checked by Parliament + courts
=> dictatorship structurally blocked
```

**Conclusion:**
> The Constitution designs a ceremonial-plus-constitutional President, not an unchecked executive.

**Directive lock:** Teaching tone + “why true” chain. No forced “critically” verdict.

### Model 2 — Discuss (multi-dimensional map)

**Q.** What are the special legislative powers of the Council of States (Rajya Sabha)? **Discuss.** *(UPPCS 2024 · 8M · 125W)*

**Why this shape:** Map the special powers as dimensions. Do not turn it into “Is Rajya Sabha useless?”

**Introduction:**
> Rajya Sabha represents the states in Parliament. Besides equal law-making on ordinary Bills, it holds a few exclusive or special legislative roles.

**Main Points:**
- **Art 249** — Can authorise Parliament to legislate on a State List subject in the national interest.
- **Art 312** — Can initiate creation of new All-India Services.
- **Ordinary Bills** — Equal power with Lok Sabha except Money Bills.
- **Constitutional Amendment** — Equal role; no joint sitting shortcut for amendments.
- **Federal Voice** — Gives smaller states a platform against pure population majorities.
- **Revision Chamber** — Second look reduces hasty legislation.
- **Limit — Money Bills** — Cannot amend or reject Money Bills; only recommend.

**Keywords (underline in exam):** Art 249 · Art 312 · Federal Chamber · Equal Power · Money Bill Limit · Revision Role

**Exam diagram (30 sec):**
```
Rajya Sabha specials
 |-- 249 (State List in national interest)
 |-- 312 (All-India Services)
 |-- equal on ordinary + amendment Bills
Limit: Money Bills
```

**Conclusion:**
> Rajya Sabha’s special powers protect federalism, though Money Bill rules keep the popular chamber fiscally supreme.

**Directive lock:** Dimensions + one limit = balanced Discuss close. No hard attack on the House.

### Model 3 — Examine (test working / how far)

**Q.** **Examine** the role of the CAG in India as the custodian of public money. *(UPPCS 2021 · 12M · 200W)*

**Why this shape:** Test the “custodian” claim with powers, reports, impact, and limits — measured close.

**Introduction:**
> The CAG is a constitutional authority under Arts 148–151. The claim that CAG is custodian of public money must be tested against audit powers and institutional limits.

**Main Points:**
- **Constitutional Status** — Independent appointment/removal design protects audit autonomy.
- **Audit Mandate** — Audits Union and State accounts, including receipts and expenditure.
- **Compliance + Performance** — Goes beyond arithmetic to economy, efficiency and effectiveness.
- **Reports to Legislature** — Audit findings feed Public Accounts Committees.
- **Deterrence Effect** — Exposure of waste and irregularities improves fiscal discipline.
- **Evidence For Custodian Claim** — No spending escapes ex-post constitutional audit.
- **Evidence Against Absolute Claim** — CAG cannot stop expenditure in real time like an executive controller.
- **Enforcement Limit** — Recommendations depend on legislative follow-up and executive response.
- **Measured Finding** — Strong ex-post guardian; not an ex-ante spending veto authority.

**Keywords (underline in exam):** Art 148–151 · Performance Audit · PAC · Fiscal Accountability · Ex-post Audit · Independence

**Exam diagram (30 sec):**
```
Public money flow -> spending departments
                \-> CAG audit -> PAC/legislature
Custodian = strong after spending, weak before spending
```

**Conclusion:**
> CAG is a powerful ex-post custodian of public money, but custodianship is incomplete without legislative oversight and executive compliance.

**Directive lock:** For/against evidence → “how far” line. Not a full Critically examine war.

### Model 4 — Analyse (parts + linkages)

**Q.** Public Interest Litigation (PIL) is an important tool for promoting social justice and protecting the rights of marginalized communities. **Analyse** with suitable examples. *(UPPCS 2025 · 12M · 125–200W)*

**Why this shape:** Break PIL into components and show how procedure, rights expansion and remedies link to social justice.

**Introduction:**
> PIL relaxed locus standi so courts can hear issues affecting the poor and unrepresented. Its value lies in how procedure, rights and remedies interact.

**Logical Analysis:**
- **Access Component** — Any public-spirited person can approach courts for collective injury.
- **Rights Component** — Expanded Art 21 to livelihood, health, environment and dignity.
- **Remedy Component** — Continuing mandamus, monitoring and guideline-based relief.
- **Linkage** — Easy access + expanded rights + creative remedies = social-justice delivery.
- **Illustration — Bandhua Mukti Morcha** — Bonded labour rehabilitation through court supervision.
- **Illustration — Olga Tellis / pavement dwellers logic** — Livelihood linked to Art 21.
- **Illustration — Environmental PILs** — Clean air/water cases protect vulnerable urban poor.
- **System Limit** — Frivolous PILs and judicial overload can weaken the tool.
- **Synthesis** — PIL works when procedure opens the door and remedies stay focused on the weak.

**Keywords (underline in exam):** Locus Standi · Art 21 · Continuing Mandamus · Social Justice · Judicial Activism · Vulnerable Groups

**Exam diagram (30 sec):**
```
PIL = access + rights expansion + creative remedies
         |            |                 |
    poor reach   Art 21 widen      monitoring relief
```

**Conclusion:**
> PIL advances social justice when access rules, rights interpretation and enforceable remedies move together.

**Directive lock:** Components → interlinks → examples → synthesis. Not only a praise list.

### Model 5 — Critically examine (merits + limits + verdict)

**Q.** **Critically examine** the main elements of the Representation of the People Act. *(UPPCS 2019 · 8M · 125W)*

**Why this shape:** Strengths of RPA design, structural gaps, then an explicit judgement + reform line.

**Introduction:**
> The Representation of the People Acts, 1950 and 1951, form the statutory backbone of elections — rolls, qualifications, corrupt practices and dispute resolution.

**Main Points:**
- **Strength — Electoral Rolls (1950)** — Provides the legal base for voter registration and territorial constituencies.
- **Strength — Conduct Code (1951)** — Governs nominations, polling, agents and election machinery.
- **Strength — Corrupt Practices** — Defines bribery, undue influence and related offences.
- **Strength — Election Petitions** — Creates a judicial path to challenge results.
- **Limit — Money Power** — Classical ceilings struggle against modern campaign finance realities.
- **Limit — Criminalisation Gap** — Disclosure and disqualification rules remain contested and incomplete in practice.
- **Limit — Enforcement Lag** — Investigation and petition timelines can blunt deterrence.
- **Verdict** — RPA is foundational and still indispensable, but not self-sufficient against money and muscle.

**Keywords (underline in exam):** RPA 1950 · RPA 1951 · Corrupt Practices · Election Petition · Criminalisation · Campaign Finance

**Exam diagram (30 sec):**
```
RPA strengths: rolls + conduct + offences + petitions
RPA gaps: money + criminalisation + slow enforcement
Verdict: necessary base, incomplete shield
```

**Conclusion:**
> RPA remains the core election statute, but purity of elections now needs stronger finance transparency and faster enforcement, not only the 1950–51 framework.

**Directive lock:** Explicit verdict. “Critically” ≠ only negative rant.

### Model 6 — Evaluate (criteria → score → judgement)

**Q.** **Evaluate** the use of VVPAT in the General Elections of India. *(UPPCS 2018 · 8M · 125W)*

**Why this shape:** Judge VVPAT against the criteria of trust, verifiability and logistics.

**Introduction:**
> Voter Verifiable Paper Audit Trail adds a paper slip to EVM voting so the voter can verify the choice recorded. Evaluation must weigh trust gains against operational costs.

**Main Points:**
- **Criterion — Verifiability** — Voter can see the printed choice for a few seconds.
- **Success — Public Trust** — Paper trail reduced pure “black box” suspicion of EVMs.
- **Success — Auditability** — Sample verification of VVPAT slips against EVM counts is possible.
- **Success — Judicial Push** — Court-monitored expansion made verification a democratic expectation.
- **Limitation — Time and Logistics** — Printing, storage and counting add burden in large elections.
- **Limitation — Partial Count Debate** — How many VVPATs to count remains a confidence flashpoint.
- **Limitation — Machine Dependence** — Does not remove the need for robust procedural integrity.
- **Judgement** — Effective as a trust and audit tool; not a complete answer to every electoral controversy.

**Keywords (underline in exam):** VVPAT · EVM · Verifiability · Sample Check · Electoral Trust · Audit Trail

**Exam diagram (30 sec):**
```
Criteria: trust + verify + logistics
VVPAT score: high on trust/verify, mixed on logistics
```

**Conclusion:**
> VVPAT has improved electoral credibility in India, provided sample audits stay rigorous and transparent.

**Directive lock:** Named criteria + scored performance + final judgement line.

### Model 7 — Comment (short informed opinion)

**Q.** COVID-19 accelerated class inequalities and poverty in India. **Comment.** *(UPSC/standard pattern · 8M · 125W)*

**Why this shape:** Opinion first, two supports, one caveat — not a full Discuss essay.

**Introduction:**
> The pandemic shock was economy-wide, but its pain was uneven. The statement is largely persuasive.

**Main Points:**
- **Support — Job Loss** — Informal and migrant workers faced sudden livelihood collapse.
- **Support — Education Gap** — Digital schooling widened the divide between connected and unconnected households.
- **Support — Health Access** — Private care costs and public overload hit the poor harder.
- **Caveat — Relief Architecture** — PDS, cash transfers and schemes blunted the worst free fall for many.
- **Caveat — Recovery Uneven** — Formal/digital sectors rebounded faster than informal labour.
- **Opinion** — COVID did not create inequality, but it compressed years of disadvantage into months.
- **Forward Line** — Shock-responsive social protection and portable entitlements remain unfinished.

**Keywords (underline in exam):** Informal Labour · Migrant Workers · Digital Divide · Social Protection · Inequality · PDS

**Exam diagram (30 sec):**
```
COVID shock
 |-- hit informal poor hard
 |-- relief reduced free fall
Opinion: accelerated inequality, did not invent it
```

**Conclusion:**
> The statement holds: COVID deepened class gaps, even where emergency welfare prevented total collapse.

**Directive lock:** Clear opinion + caveat. Shorter than Discuss/Evaluate.

### Model 8 — To what extent (degree answer)

**Q.** **To what extent** can Alternative Dispute Resolution (ADR) strengthen justice delivery in India? *(pattern from UPPCS ADR questions · 8M · 125W)*

**Why this shape:** Neither “ADR is perfect” nor “ADR is useless” — degree + limits.

**Introduction:**
> ADR covers arbitration, mediation, conciliation and Lok Adalats. Its contribution is real but bounded.

**Main Points:**
- **Extent — Speed** — Settlements reduce pendency for suitable civil and compoundable disputes.
- **Extent — Cost** — Lower expense improves access for ordinary litigants.
- **Extent — Relationship Repair** — Mediation preserves business and family continuity.
- **Extent — Lok Adalats** — High disposal in motor-accident and petty compoundable matters.
- **Limit — Criminal Core** — Serious crimes still need full criminal process.
- **Limit — Power Asymmetry** — Weak parties may settle under pressure.
- **Limit — Quality Variance** — Outcomes depend on mediator skill and consent quality.
- **Degree Line** — ADR strengthens delivery **to a significant extent** in civil/commercial/compoundable zones, **not** as a substitute for the entire court system.

**Keywords (underline in exam):** Arbitration · Mediation · Lok Adalat · Pendency · Access to Justice · Consent

**Exam diagram (30 sec):**
```
ADR helps a lot: civil + commercial + compoundable
ADR helps less: serious crime + unequal bargaining
Degree: significant, not total
```

**Conclusion:**
> ADR is a strong complement to courts, not a full replacement — its extent is high where consent and civil stakes dominate.

### Model 9 — Compound (Examine + Suggest)

**Q.** **Examine** the major issues of dispute between India and Bangladesh and **give suggestions** for improving bilateral relations. *(UPPCS 2024 · 12M · 200W)*

**Why this shape:** Two verbs → two labelled blocks (~60 / 40).

**Introduction:**
> India–Bangladesh ties are among India’s closest neighbourhood relationships, yet water, border and connectivity frictions persist.

**Main Points — Examine:**
- **Water Sharing** — Teesta and other river arrangements remain politically sensitive.
- **Border Management** — Smuggling, illegal migration perceptions and fencing frictions continue.
- **Trade Asymmetry** — Connectivity gains coexist with market-access complaints.
- **Security Spillover** — Extremist and trafficking concerns need joint handling.
- **Domestic Politics** — Internal politics in both countries can freeze technical deals.

**Main Points — Suggest:**
- **Water Diplomacy** — Revive Teesta-type talks with interim technical sharing formulas.
- **Border Confidence** — Expand coordinated patrols, integrated check posts and people-friendly border haats.
- **Connectivity Push** — Faster rail, inland water and energy grid projects.
- **Development Partnership** — Lines of credit tied to transparent, local-benefit projects.
- **Institutional Habit** — Keep annual mechanisms running even when politics is noisy.

**Keywords (underline in exam):** Teesta · Border Management · Connectivity · Neighbourhood First · Joint Patrols · Trade Facilitation

**Exam diagram (30 sec):**

## Practice drill (one theme, four verbs)

Pick any syllabus theme you already know (GST Council, Basic Structure, MGNREGA, QUAD, Urbanisation).

Write **four 8-mark skeletons** in one sitting:

1. Explain …
2. Discuss …
3. Examine …
4. Critically evaluate …

Do not add new facts between versions. Only change **shape, headings, and close**.  
This drill trains the verb faster than collecting a new source.

**Extra drill from this page:** Cover Models 1–6. Recreate only the **closing sentence** from memory — if the close matches the verb, the answer shape is usually safe.

## One-page memory card

```
Describe / Enumerate  -> list features
Explain / Elucidate   -> What-Why-How + example
Discuss               -> map dimensions / both sides -> balanced close
Examine               -> test claim / working -> measured close
Analyse               -> parts + linkages -> synthesis
Comment               -> short opinion + proof
Evaluate / Assess     -> criteria + weigh -> verdict
Critically ...        -> merits + limits -> VERDICT + way forward
To what extent        -> degree answer (largely / partially)
Suggest               -> named, doable reforms
```
