# UPPCS Mains — Official Syllabus Index

> **Source of truth** for folder structure in `mains-pyqs/`.  
> **Rule:** 1 syllabus **Topic** = 1 folder · 1 **Subtopic/keyword cluster** = 1 `.md` file  
> **360° rule:** Each subtopic file covers every exam dimension for **that keyword only** — not the whole parent topic.

---

## How to Read This File

| Level | Meaning | Folder / File |
|-------|---------|---------------|
| **Paper** | GS-I … GS-VI | `mains-pyqs/GS-1/` |
| **Topic** | Official numbered syllabus bullet | `GS-1/01_Art_Culture/` |
| **Subtopic** | Keyword cluster — one standalone answer theme | `01_Mauryan_Art_Architecture.md` |
| **PYQ** | Past Mains question(s) mapped to subtopic | Inside subtopic file's PYQ Map |

### When to split vs merge subtopics

| Do ONE file | Do SEPARATE files |
|-------------|-------------------|
| PYQs always ask same period/theme (Mauryan art + Mauryan architecture) | Different syllabus keywords (Vedic **literature** vs Nagar **architecture**) |
| Same ammunition bank serves all PYQs | Different eras, sources, or art forms |
| ≤5 PYQs, one angle | Keyword in syllabus is distinct (Women ≠ Urbanization) |

## 360° Keyword Coverage (mandatory per subtopic file)

For **each subtopic keyword**, the file must cover:

| Dimension | What to include |
|-----------|-----------------|
| **Define** | Exam-ready definition of the keyword |
| **Origin / Background** | Historical context, period, sources |
| **Features / Characteristics** | Salient points (bullets) |
| **Significance / Contribution** | Why it matters — India/world |
| **Examples** | Sites, texts, monuments, persons (≥3) |
| **Comparison** | With other periods/styles if relevant |
| **Contemporary relevance** | Present-day significance (if PYQ asks) |
| **Criticism / Limitations** | For critical directives |
| **PYQs** | All Mains PYQs on this keyword |
| **Traps** | Common wrong statements |
