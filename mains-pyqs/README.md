# mains-pyqs — Quick Start

## Architecture (read this first)

```
GS-1/01_Art_Culture/          ← Syllabus Topic 01 (folder)
  01_Mauryan_Art_Architecture.md   ← ONE keyword (file)
  04_Vedic_Literature.md           ← different keyword = different file
```

**Not:** one file for all of Art & Culture.  
**Yes:** 360° on each keyword in its own file.

Full syllabus map: `00_SYLLABUS.md`

---

## Create a subtopic file

1. Open `00_SYLLABUS.md` → find Topic # + subtopic + file path  
2. Fill `TOPIC_INPUT.md` with **one keyword's PYQs only**  
3. Run prompt from `TOPIC_INPUT.md`  
4. Verify Delivery Report: **Solvability 100%** (AI only — not in student file)

---

## Daily read order (student file)

1. **Quick Revision** (5 min)
2. **Answers** — one PYQ (alternate days)
3. **Traps** — before writing practice

Student files have **6 sections only** — no keyword maps, checklists, or meta tables.

**Diagrams:** 0–2 **mermaid** blocks inside **Content** when structure/spatial layout helps memory (corpus layers, temple parts, expansion flows). Not in Answers/Traps. See `prompt.md` + `_GOLD_STANDARD.md`.

**Book-free:** each file must cover the full keyword — you should not need NCERT/other notes for that subtopic.

**Enriched standard (July 2026):** Content ≥1200–1500 words · `### Contemporary relevance` subsection · 10–12+ traps · UNESCO/NEP IKS/ASI links where exam-relevant. See `prompt.md` enrichment rule.
