## 11. Answer-writing format (from subtopic files)

1. **Introduction** — definition + scope (1–2 lines)  
2. **Labelled bullets** — 6–8 (8M) / 7–9 (12M); each = **keyword + fact**  
3. **Keywords line** — 4–7 underline targets  
4. **ASCII diagram** — 30 sec, margin-drawable  
5. **Balanced conclusion** — especially for *critical examine*  

| Directive | Approach |
|-----------|----------|
| Critically examine | Pros + cons + verdict |
| Analyse | Mechanism + examples + limits |
