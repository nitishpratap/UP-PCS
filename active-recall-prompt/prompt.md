## TWO-PHASE STRUCTURE (mandatory)

Active recall files have **two phases in order**. User studies Phase 1 first (build memory), then Phase 2 (exam framing).

### Phase 1 — Foundation Active Recall `[RECALL]`

| Rule | Detail |
|------|--------|
| **Minimum** | **25 questions** (aim **28–30** for dense topics) |
| **Purpose** | Direct memory — retrieve facts **before** MCQ traps |
| **Style** | Short prompts: *Who / What / Which Article / List / Name / Explain in 2–3 lines* |
| **No MCQ codes** | Do **not** give A/B/C/D options in Phase 1 |
| **Coverage** | **Every** dimension from notes + syllabus supplement — one pass through the whole topic |
| **Answer format** | Concise bullets/tables inside toggle; optional **Key point** line |
| **Blocks** | Group by sub-topic (Block A, B, C…) under heading `## Phase 1 — Foundation Active Recall` |

**Phase 1 question tag:** `[RECALL]` only.
